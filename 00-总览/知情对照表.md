# 知情对照表

> 同一事物：各地圈内怎么说，设定上实际是什么。  
> 圈内叙事可以与设定真相冲突——这是允许的，不是错误。  
> 写某一区的圈内文案，只用该区口径；设计跨区因果与反转，以设定真相为准。

母设定没有单一玩家。子设定集的「玩家以为 X、实际是 Y」见各集对照表，不在本表重复：

- 云上坟场：[明暗对照表](../分支时间线/法厄同/云上坟场/00-总览/明暗对照表.md)

| 奥菲昂·卡律布狄斯 | （法厄同／击魄玩家可见文案不点名） | 太空失控异魔集群凝聚的大群意志；是大群对人类用暴力解决问题之理解的化身。细节见 [异魔](../词条/参与者/污染/异魔.md) |

| 巴力 | 某地的主人／神／王 | 自然产生的地方神／地灵（原初混沌者），与从天降临的原初魔神不同源 |
| 原初魔神 | 术数记载「七十二柱」；找到延续之法者称七罪神 | 人类源质化后的衍生，自天降临；实际数量不定 |
| 伊勒（El） | 节点城正典：有意识、持续在场、能主动施加影响的最高神 | 无灵魂的灵体，顺从宗教为其安排的位置，持续履行教义所赋使命；历代教宗常把这种执行误读为「宽容」 |
| 路西法 | 正典：妄图与伊勒并立，被米迦勒击败，从天空摔入地下，放逐为恶魔与魔鬼之王 | 欲驯化伊勒为文明工具；天使阶层为既得利益将其放逐至灵界。灵界不是独立故事地区，不另开线 |
| 洋与殁 | 海潮派／伊勒教：伊勒收养的圣子，庇佑信徒的神兽；长子洋为洪水与混沌化身，次子殁为惩戒与死亡化身 | 类乎巴力的存在，因海潮派在以太中的活动被引来，后在以太界与伊勒交战不敌而被收服 |
| 云上人 | 法厄同带：高贵数字居民、航班司机、监测站管理员；A 站明线另有一层（见该集对照表） | 合规上传、并在法厄同带内取得云邦官方授权后，法律与道德身份为**人类**（[云上人](../词条/参与者/族群/云上人.md)） |
| 人工智能 | 表现得像人时，圈内仍可能按人来对待 | **不是人类**。来源包括被制造的智能，以及思维上传不合规者 |

## 三、范围与切法（写错主语就会串台）

| 事物 | 容易写成 | 设定真相 |
|------|----------|----------|
| 云邦 | 太阳系联邦、各地云城的共同政权 | 只存在于法厄同带；其它轨道的云城各归当地 |
| 麦哲伦号 | 云邦旗舰 | 在卢娜建造，从泰拉轨道出航；云上人参与建设，但舰不属于云邦 |
| 核心区 | 等于矿区、等于工业区 | 三个创始州所在；最大铀矿在东亚合作社那一创始州**附近**，不在「核心区等于矿区」这个等式里 |
| 边缘区 | 等于尚未成州 | 地理上偏远、还在开发；里面既可以有州，也可以有领地 |
| 州／领地／辖区 | 互相替代；把所有基本单位都只称为州 | 基本单位是成员。州是成员的一种，也是获准后的正式会员。地上国的附属机构也可以作为成员。领地尚未成州，不是成员。辖区只表示谁在管的那一块地方 |
| 以太 | 日常能源 | 灾前只作航行介质；灾后直至破晓早期仍不参与日常能源供给 |
| 外溢 | 马尔斯与法厄同之间另有一处舞台 | 污染现象；两地相距以天文单位计 |

废弃缩略与废弃等式见 [CONTEXT.md](../CONTEXT.md) 的 `_Avoid_`。以后正文一律用完整说法。

## 四、地面人群（勿把两套自称压成一团）

| 事物 | 圈内／自称 | 设定真相 |
|------|------------|----------|
| 城市人 | 内城人；伊勒选民 | 节点城一系；用以太壁垒隔绝以太 |
| 荒原人 | 荒野人；部分聚落自称城邦（The Enclaves） | 未被节点城保护、长期暴露于以太异变中的人群 |
| 外城平民 | （节点城内部阶层） | **不等于**荒原人；长期暴露者部分荒原化 |
| 哈达德众城邦 | 巴力·哈达德麾下港城、山城、高原城 | 诸城所在之地东部—东南沿海子区；勿与荒原聚落所称城邦混淆 |
| 执火派／执火者 | 教内异端；荒原侧另有执火军 | 教内执火派追随路西法，不承认现世伊勒正统；昏昼的荒原执火军是另一支 |
