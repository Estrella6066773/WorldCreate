# 母设定 · 总览

本文件夹是母设定的**导读入口**：让新读者在几页之内知道这个世界是什么、哪些规则不能破、该从哪条线读下去。细节仍以词条为准，各区故事仍以分支时间线为准。

> **不是游戏总览。** 云上坟场、击魄各有玩家视角（明线）与世界背景（暗线）。母设定没有单一玩家，知情分层是**圈内叙事／设定真相**，不是明线／暗线。圈内有多套口径，故不单开「明线总览」。
> 跨区「谁对谁做了什么」的接口表仍在 [总世界线](../总世界线.md)，本夹不抄那张表。

---

## 文档职责

与子设定集同一套切法：总览只导读，不替代正文与词条。

| 层级 | 文件 | 职责 |
|------|------|------|
| 总览 | 本夹 | 一句话、世界规则、连贯速读、规模、导航、阅读路线 |
| 对照 | [知情对照表](知情对照表.md) | 同一事物：各地圈内怎么说，设定上实际是什么 |
| 待定 | [待定项汇总](待定项汇总.md) | **母设定层**待定的唯一索引；子设定待定不收入此处 |
| 接口 | [总世界线](../总世界线.md) | 分层树 + 跨区接口表 |
| 正文 | [分支时间线](../分支时间线/README.md) | 各区因果；上层只索引 |
| 词条 | [词条](../词条/README.md) | 时间／地点／参与者／事件的细节权威源 |
| 词汇 | [CONTEXT.md](../CONTEXT.md) | 已决议术语；废弃缩略见其中 `_Avoid_` |
| 名录 | [实体与关系网](../实体与关系网.md) | 已点名实体的扫描表，不是导读 |

写作圈内文案只引该圈自己的说法；设计跨区因果与反转以设定真相为准；查「各地是否在说同一件事」用对照表。

## 两层正交

1. **知情分层**：圈内叙事（某派系、职阶、时代人物自认或正典所述）对设定真相（作者定稿，可与圈内冲突）。子设定集另有明线／暗线，只服务该集的玩家视角，不升格为母设定切法。
2. **存储轴**：时间／地点／参与者／事件。四条线内部可以再分，不必摊平。

| 线 | 只存 | 不存 |
|----|------|------|
| 时间 | 时代先后、本库共用的三截 | 谁做了什么的过程 |
| 地点 | 天体、地表、轨道、以太界、云城 | 在该处发生的事件全文 |
| 参与者 | 能作主语的一方 | 事件因果链 |
| 事件 | 跨区的「谁对谁做了什么」 | 把履历或地理志写进事件 |

## 阅读路线

- **新读者：** [设定真相·总览与导读](设定真相·总览与导读.md) → 选一条分支时间线通读 → 按需要进词条
- **写某一区：** 先读该区地点 README 与分支时间线；跨区只引用 [总世界线](../总世界线.md) 已有接口，不把对方内部写进本区
- **写玩家可见文案：** 进对应子设定集的明线总览；母设定本夹含剧透，不得直接用于玩家文案
- **查各地是否在说同一件事：** [知情对照表](知情对照表.md)
- **查未决事项：** [待定项汇总](待定项汇总.md)；子设定内部待定见该集自己的汇总
