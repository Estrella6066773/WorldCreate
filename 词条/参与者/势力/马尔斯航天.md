# 马尔斯航天

## 概述

- 马尔斯轨道与地表殖民开发的主导企业；亦称**战神航天**，与马尔斯航天互指同一组织。
- 不由[云邦](云邦.md)管辖。处置本区[穿越机](../污染/穿越机.md)污染与后续压制，属本组织及其理事会。

## 理事会

高级事务由**马尔斯航天理事会**议决。另有内部议会，以及流动性较大的议员。

| 阶段 | 理事会构成 | 说明 |
|------|------------|------|
| 灾前 | **6 席**：地上 3 席、云城 3 席 | 地面据点规模较小，权力核心在云城。内部议会并行 |
| 殖民地扩展之后 | 席位随殖民地扩大而调整 | |
| [智库](智库.md)总控被封存修剪之后 | **12 席**：地上三大基地 9 席、云上空间站 3 席；另有流动性较大的议员 | 总控封存后，高级事务改由人工决策 |

## 关系

- [智库](智库.md)：封存前优先照顾本企业利益；曾以总控身份参与穿越机项目管理
- [穿越机](../污染/穿越机.md)：本企业在马尔斯轨道部署的云城研发
