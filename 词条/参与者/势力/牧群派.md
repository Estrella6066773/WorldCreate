# 牧群派

## 概述

牧群派是[伊勒](../至高存在/伊勒.md)信仰中受以太壁垒庇护的一支，也是[节点城网络](../../地点/泰拉/地面/诸城所在之地/节点城网络/README.md)的教会正统本身。它认为壁垒为伊勒所赐、以太之力则是惩戒洪水的余波，久居于壁垒之内，与行于滨海与荒原的[海潮派](海潮派.md)构成本教内部的两条路线。

在教会自己的表述里，它不叫牧群派，只称**教会**：伊勒在人间的正统，此外的伊勒信众都是走了岔路的人。「牧群派」是旁人为了区分教会本体与海潮派而加的别称。

教会内部再分两重身份：主持教义阐释与仪式的教会成员自称**神的牧羊人**（到牧师一级，便可自称「牧者」），受牧养的信众是**神的羔羊**。牧群即二者合成的整体——牧者与牧群。

主故事线：[城市与城邦](../../../分支时间线/泰拉/地面/诸城所在之地/城市与城邦.md)（🟢 城市与城邦）。

## 教义核心

### 一、壁垒**乃**伊勒之赐

海潮派的根本命题是「洪水乃伊勒之力」。


|        | 海潮派      | 牧群派      |
| ------ | -------- | -------- |
| 一句话    | 洪水乃伊勒之力  | 壁垒乃伊勒之赐  |
| 对信众的期待 | 主动追寻伊勒之人 | 听从牧者引领之人 |
| 恩典的性质  | 人人有份的本钱  | 有等差的分授   |
| 人的姿态   | 主动、向上攀   | 安分、留在原处  |
| 对外的方向  | 向外走      | 向内收      |


两派都承认伊勒为最高神格，分歧就落在这一句上：一方说恩典是伸手去拿的东西，一方说恩典是被牧养的状态。

### 二、洪水史的牧群派读法

伊勒教把大洪水分为潮涌、洪泛、余波三个阶段，作为纪年框架（见[伊勒](../至高存在/伊勒.md)）。牧群派的读法：


| 阶段  | 牧群派读法                                   |
| --- | --------------------------------------- |
| 潮涌期 | 伊勒降罚，未受庇护者被溶解；这是一场筛选，栏外的都死了             |
| 洪泛期 | 伊勒在旷野中立栏，把秩序交给受拣选的人；职阶与诸天监督于此期定下，此后不容改动 |
| 余波期 | 洪水未收尽，旷野仍在；栏必须守住                        |


两派用同一个余波期推出了相反的结论：海潮派走向海，牧群派守住栏。

### 三、牧羊人与羔羊

教会以牧养比喻自身结构，并把这套比喻落进职阶：

- **神的牧羊人**：教会成员，主持教义阐释、仪式与裁决，亦兼任官僚、司法、档案与文书。升到牧师一级，可领受教会授予的**名誉牧者**称号。「牧者」一词兼有两义：在教会内指这一神职阶位，在[城市人](../族群/城市人.md)职阶中指罗埃。
- **神的羔羊**：信众。羔羊的本分是留在栏内、受牧养、走牧人指的路。

牧群派由此解释了职阶的由来。「享有神最多／中等／最少的恩惠」这组等差，在牧群派读来是**神分派的照顾**：有人在栏的中心，有人在栏的边缘，但都在栏内。有了这层解释，职阶不是阶层，而是牧养的次序，因而在教义上站得住。

### 四、栏内的神

以太壁垒隔绝以太，伊勒在城内因此不能被直接感知或召请。牧群派的日常信仰经由中介完成：神迹、裁决与秩序由神职转述，信众从中体验伊勒的在场，并把政治与社会的重大结果归因于神意。

对照海潮派「自己走进荒原、自己承受以太」的直接路径，中介与直接是两派的又一处对立。

### 五、出栏：朝圣

出栏只有一条合法路径：**朝圣**。信众或赴其他节点城交流教义，或赴被毁节点城的遗址举行仪式。私自出城是罪，为伊勒出城是虔敬。

朝圣带回的仪式产物在外城教堂加工为**圣木、圣蜡、圣油**，以特制神龛或固定仪轨燃烧，可在聚居点内达到一定程度抵御以太侵袭、削减以太浸染的效果。其效力不及节点城以太壁垒——这一点在牧群派教义里正好印证恩典有等差：栏中心的庇护最厚，栏边缘的只能靠圣物补足。

### 六、正统的来历

节点城链接瘫痪期间，伊勒「降临」于[巴别尔](../../地点/泰拉/地面/诸城所在之地/巴别尔/README.md)，于旋塔之顶册封诸天使。牧群派把此事视为正统的源头：诸天监督与职阶秩序由伊勒亲定，此后不容改易。天使长路西法妄图与伊勒并立分权，被米迦勒击败放逐；追随路西法的[执火派](执火者.md)由是被定为异端。

## 设定真相

- 以太壁垒技术由[轨道研究站](../../地点/泰拉/轨道/轨道研究站/README.md)在灾前一次交付给地面节点城，节点城是统治层自己建的；牧群派把它读作伊勒的赐予。
- [伊勒](../至高存在/伊勒.md)是无灵魂的灵体，顺从宗教为它安排的位置，持续履行教义所赋使命；历代教宗将那无条件的执行误读为「宽容」。

两者合起来，是牧群派可以承载的悲剧：他们把自建的高墙读作了神的赐予，把空洞的沉默读作了恩典。分层对照见[知情对照表](../../../00-总览/知情对照表.md)。

## 与其他群体的关系


| 对象                  | 关系                                     |
| ------------------- | -------------------------------------- |
| [海潮派](海潮派.md)       | 同一信仰内的路线之争：栏内对出栏，牧养对伸手                 |
| [执火派](执火者.md)       | 教会法统中的异端；不承认现世伊勒的正统，追随路西法              |
| [荒原人](../族群/荒原人.md) | 栏外的存在；城市人对其隔离、驱散、奴役与清剿，牧群派不把荒原人算在受拣选之列 |
| [天赋者](../族群/天赋者.md) | 受染余毒更重的人；城市人猎杀天赋者，教义上的理由是清理未净之物        |
| [巴力](../至高存在/巴力.md) | 荒野的地方神；与伊勒并不同源，不属受拣选谱系                 |
| [城市人](../族群/城市人.md) | 信仰主体；牧群派是城市人教会秩序的神学形态                  |
