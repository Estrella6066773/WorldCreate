# 精灵

漂泊至此的精灵分支：尖耳、淡色头发、寿命悠长、能操纵植物。原居远离众城的隔绝天国；家乡神木与天国地面称**世界树**，精灵惯称**祖树**。特征不源于大灾变。

大天灾中祖树异变，操纵植物的能力被环境削弱。少数精灵逃离（明知家乡灾情更轻，近于投机），大部分不再守戒，后来在此地过得不错。后来与远离城市的[荒原人](荒原人.md)联系；不守戒的后辈常出现在[巴力](../../参与者/至高存在/巴力.md)神殿，任圣女或其他高位侍从——寿命悠长，比人类更适于长期辅佐。城市人曾蔑称「食马者」；偏见很少传到荒原，普通人多因神殿职事视其为高洁。

[月人的起源](../../../分支时间线/卢娜/月面/月人的起源.md)参考制造精灵的技术，研发能主动接纳以太且有一定抗性的月人。

地点见 [世界树](../../地点/泰拉/地面/世界树/README.md)。故事见 [自远方祖树而来的精灵们](../../../分支时间线/泰拉/地面/世界树/自远方祖树而来的精灵们.md)。
