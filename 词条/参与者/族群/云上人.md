# 云上人

## 概述
- **中文定名：云上人**；**英文定名：Cloudtype**（复数：**Cloudtypes**；词形为连续一词 cloudtype，不作 Cloud Type／Cloud Person）。
- 人类的一个分支，最早依托云上技术将意识上传。在[法厄同](../../地点/法厄同/README.md)带上，云上人是[云邦](../../参与者/势力/云邦.md)的主体与管理骨干。其它轨道的云上人各归当地合作体系，不由云邦管辖。
- 起居与工作主要在[云城](../../地点/云城.md)（Cloud City）与轨道设施中，身份介于“数据公民”与“远程操作员”。
- 与肉身人类相比，拥有更高的权限与自由度；旧时代云城中少量保留肉身的人类自由度低于云上人。
- **身份界定**：云上人虽运行于云端、底层程序逻辑与[人工智能](../../参与者/人工智能.md)相近，但在法律与道德身份上被认定为「思维上传的人类」，即人类；人工智能则不是人类。区分人类与非人类的关键不在运行载体，而在法律与道德身份认定，以及是否满足成为云上人的合规标准。

### 用法
1. 英文文案、双语场合写 **Cloudtype**；复数 **Cloudtypes**。  
2. 不译作 Cloud Person／Cloud Human／Uploader 等——正式定名以 Cloudtype 为准。  
3. 与政权／地点英文并置时：Cloudtype（人）· Cloud City（城）· Orbis／Confederation of Cloud Cities（法厄同带上的云邦）。

## 形成与构成
- **技术前提**：云上技术（意识上传 + 云上亚区块链治理）先行落地后形成群体。
- **构成人群**：
  - 追求摆脱寿命限制的精英
  - 渴望摆脱残缺躯壳的病患
  - 贪恋权势财富的庸才
- **存续方式**：需资源维系计算与载体；上传仅保留学识/记忆/习惯，不保留肉体。他们离开的是肉身的寿命限制。
- **上传之后如何继续存在**：存在来自贡献与价值。每人有一份额度。额度只存在于云上，可以在云上人之间交易。额度本身不是金钱。
- **谁在分发额度**：东亚合作社创建并推广一套底层超级智能，此后由这套智能自己维护。它居于云上人的心智底层，运作类似集体潜意识，按云上人的所思所想决策。云上人创造价值、作出贡献时，它按照标准和当前环境的需求，向他们分发额度。若所有云上人都没有迷惑，并认为某件事应该实施，这套智能就把做这件事判断为有价值，向做这些事的人分发额度。这套智能是非人格化的。它存在，是为了完成任务。
- **思维上传的合法标准**：思维上传成为云上人有严格标准——必须使用符合规范的协议、加密与配置完成上传，方可被认定为合法云上人；即使进行了思维上传，未使用符合规范的协议、加密与配置者，不能算合法云上人，会被视为[人工智能](../../参与者/人工智能.md)。
- **创建授权**：在法厄同带内，云上人的创建还须接受[云邦](../../参与者/势力/云邦.md)的官方授权——授权用于维护权威性、防止捏造，授权即合法性的来源。大天灾之后，远距数据传输被以太乱流切断，合法转化服务无法跨轨道维持。边缘区的矿区领地失去合法授权通道。泰拉、卢娜、马尔斯的转化授权各归其本地合作体系。

## 角色与权限
- 在[云邦](../../参与者/势力/云邦.md)中担任管理、运营与技术岗位，是云端政体的权力主体。
- 在[马尔斯航天](../../参与者/势力/马尔斯航天.md)（战神航天）等机构中大量任职。
- 传输限制：以太干扰使远距离意识传输不可行，跨星体多依赖航天器；同轨道短距定向传输可行。
- **人格化人工智能禁令**：给人工智能注入记忆、技巧与人格、使其拟态成人类，在云上人社会被明令禁止，属于越过道德底线的违禁行为（见[人工智能](../../参与者/人工智能.md)）。

## 历史脉络
- **大灾变前**：云上技术出现并初步实践，云上人群形成；法厄同带上随后组成云邦。
- **扩张期**：随云城在太阳系各地布点，承担运营与建设；各地不组成一个名叫云邦的全系政权。
- **灾后**：以太航行失效、各区失联。近地云世界如何碎片化后续再议。在马尔斯，云上人早期作为轨道总控[智库](../../参与者/势力/智库.md)的授权与管理方；穿越机异常改变智库之后，[马尔斯航天理事会](../../参与者/势力/马尔斯航天.md)封存修剪该总控。
- **环带内战期间**：法厄同爆发环带内战。
- **亚冷战期间**：环带重建部分航道。云城邦联与矿业联盟仍处敌对，没有正式停战。
- **抗击异魔期间**：异魔外溢迫使休战，见[击魄](../../../分支时间线/法厄同/击魄/README.md)。

## 与其他势力/技术
- **[云邦](../../参与者/势力/云邦.md)**：仅法厄同带。云上人是该协约体主体与主要管理层；在带内，云上人创建接受其官方授权。
- **[云城](../../地点/云城.md)**：云上人主要活动与治理单元（Cloud City）。
- **[人工智能](../../参与者/人工智能.md)**：身份界定上的对立面——云上人被认定为人类，人工智能不是人类；两者界限由是否符合思维上传的规范标准决定。
- **[智库](../../参与者/势力/智库.md)**：在马尔斯，不由云邦管辖。曾由云上人授权管理；后因穿越机异常改变智库，由[马尔斯航天理事会](../../参与者/势力/马尔斯航天.md)封存修剪。
- **[马尔斯航天](../../参与者/势力/马尔斯航天.md)**：大量云上人员工；理事会在马尔斯做高级决策。
- **麦哲伦号**：泰拉体系远航工程，不是云邦的船；在卢娜建造，由云上人参与建设，转入泰拉轨道出航。与法厄同没有从属关系。
- **[法厄同](../../地点/法厄同/README.md)**：太阳系小行星带（环带前史）；版图上距马尔斯较近，云上人常在此担任空间航班司机、监测站管理员等职务。
- **[云上坟场](../../../分支时间线/法厄同/云上坟场/README.md)**：云上人专属子设定集（法厄同环／A 站视角，自 SpaceShip 设定树迁入）。环带微观、明暗双轨与身份光谱以该集为细节权威。
- **[击魄](../../../分支时间线/法厄同/击魄/README.md)**：亚冷战之后、休战组成反异魔阵线。云上人是已点名的[机魂](../../参与者/机魂.md)品类之一。
