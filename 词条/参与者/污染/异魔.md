# 异魔

## 三层

| 层 | 是什么 |
|----|--------|
| 土壤 | [穿越机](穿越机.md)的伪人格化异常像环境，孕育或影响其中的非人意志 |
| 异魔（严格） | 这份土壤在物质一侧的显现。异魔主要是原先有意识、因暴露在真实世界中而被异化的实体。本质来自穿越机 |
| 称呼扩展 | 「异魔」也用来称呼被穿越机影响的载具、设施、动物。严格叙述时写清：它们是感染对象或附着结构，还是已有被异化意识的主体 |

人们常遇到的异魔会感染有灵体，并把船体、灵魂与被污染之物融合，重组为可继续释放感染力的扭曲个体。

同一现象，各地区用本地称呼、写本地故事。跨区只认「外溢／坠落」，不互抄对方内部剧情，也不另设中间地点。

## 奥菲昂·卡律布狄斯（设定真相）

太空中失控的穿越机／异魔集群，在大量集群离开轨道、受到人类暴力处置之后，自我凝聚成**没有个体、只有大群**的非人意志。设定上称**奥菲昂·卡律布狄斯**（Ophion Charybdis）。

奥菲昂·卡律布狄斯是大群对「从马尔斯到法厄同，人类一贯用暴力解决问题」这一行为的凝聚，也是大群对暴力之理解的化身。异魔集群的特殊性可能引来世界深处的目光；大群在失去原先由人派出的掌控者之后并未凋亡，反而更诡谲，并开始生产人类尚未理解之物（例如人类不曾传授的机体设计、更诡异的以太物质）。细节待写。

法厄同带正文只写外溢所见之异魔，不写奥菲昂·卡律布狄斯的专名与大群内幕。

## 马尔斯如何解决异魔

马尔斯解决异魔的原理是：让宿主锚定，控制异魔，并集中销毁。宿主本身也会被异魔污染。

宿主锚定这一原理，不由「以太投射导致原型泄露」那一机制导出。污染已经在轨道与地表扩散之后，[马尔斯航天](../势力/马尔斯航天.md)可以采用宿主锚定来应对。封存智库、封存原型、以太投射泄露，见 [穿越机](穿越机.md) 与 [开拓马尔斯](../../../分支时间线/马尔斯/开拓马尔斯.md)。

送一个人进去把材料稳住，再把这个人和材料一起毁掉，是还没写完的叙事。马尔斯侧用派遣、学者、监牢、宿主锚定来写这件事；其中承担锚定、管理穿越机／异魔集群的人，马尔斯称为穿越机管理员一类职务，**不**称为魔王。法厄同带同样不把任何人称为魔王。

**魔王**只出现在泰拉地面：当地人称异魔为渊魔或魔物，因而把统御异魔者称为魔王。此人可以与马尔斯侧派出的穿越机管理员是同一存在；「魔王」是地面因渊魔／魔物这一套称呼推出来的名，不是马尔斯或法厄同的职务名。

## 作者层

这一节记作者写异魔想表达什么。它不是世界里的一段经过。

作者把异魔写成放大镜。被战争使用过的设施和武器，被异魔重新塑起之后，继续造成更多破坏。口头说的「来造福人类」是反话，指的是附身在人工智能武器上，向战后剩下的资产输出能量。作者要让人看见，破坏比建立容易。
