# 泰拉

## 概述

- 人类文明的母星，太阳系第三行星；叙事中地表活动与泰拉轨道设施分属多条故事线交汇的舞台。
- 下设两大子类：**[轨道](./轨道/README.md)**（源质实体的起源、环带前史基建）与 **[地面](./地面/README.md)**（城市与城邦／自远方祖树而来的精灵们）。地面另含 **[深渊](./地面/深渊/README.md)**（渊魔坠落区）。
- 本文件只作泰拉分层索引；各子区写各子区故事。
