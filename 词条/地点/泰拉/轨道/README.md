# 轨道

## 概述

- [泰拉](../README.md)的轨道区域；前文明末期集中布设太空设施。此处**没有**规模很大的工业云城：产业以服务业为主，仅有少量轻工业；云城与空间站多为驿站、服务站与景点。重工业在月面（见 [月人的起源](../../../../分支时间线/卢娜/月面/月人的起源.md)）与泰拉地面更成熟。大天灾后与地外殖民地（如[马尔斯](../../马尔斯/README.md)轨道）之间的航道多被切断，设施各自陷入孤立或弱联系状态。
- 下设两处子地点：**[轨道研究站](./轨道研究站/README.md)**（源质实体的起源）、**[泰拉轨道服务器阵列](./泰拉轨道服务器阵列/README.md)**（环带前史）。

- 服务器阵列：当地云端底座（不叫云邦）。大灾后与地外殖民地失联。
