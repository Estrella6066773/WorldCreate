# 轨道

- [泰拉](../README.md)的轨道区域；前文明末期集中布设太空设施，大天灾后与地外殖民地（如[马尔斯](../../马尔斯/README.md)轨道）之间的航道多被切断，设施各自陷入孤立或弱联系状态。
