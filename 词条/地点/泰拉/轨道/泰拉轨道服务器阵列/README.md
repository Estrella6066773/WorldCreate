# 泰拉轨道服务器阵列

## 概述

- [泰拉轨道](../README.md)上为云世界提供基础设施的服务器阵列。

## 性质与关联

- **功能**：泰拉轨道上云城网络的云端底座之一，支撑当地云上技术与云城节点运转。**不叫云邦**——云邦只存在于法厄同带。
- **建设**：前文明末期，云上技术落地后于泰拉轨道建立。
- **与研究站**：灾前以太航行技术来自 [轨道研究站](../轨道研究站/README.md) 一次交付；大天灾后本阵列对研究站求援未至（对方内部见以太线）。正文在 [云上线](../../../../../分支时间线/法厄同/云上线.md)。
