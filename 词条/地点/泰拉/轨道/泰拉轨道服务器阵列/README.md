# 泰拉轨道服务器阵列

## 概述

- [泰拉轨道](../README.md)上一座云城的站内节点阵列，为当地云上世界提供基础设施。
- 主故事线：[环带前史](../../../../../分支时间线/法厄同/环带前史.md)（🟡 环带前史）。

## 性质与关联

- **功能**：泰拉轨道上一座云城的站内节点阵列，承载当地云上世界与云上人。云邦只存在于法厄同带，本阵列不属于云邦。
- **建设**：前文明末期，云上技术落地后于泰拉轨道建立。
- **与研究站**：灾前以太航行技术来自 [轨道研究站](../轨道研究站/README.md) 一次交付；大天灾后本阵列对研究站求援未至（对方内部见源质实体的起源）。正文在 [环带前史](../../../../../分支时间线/法厄同/环带前史.md)。
