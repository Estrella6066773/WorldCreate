# 深渊

城市与城邦对坠落区的称呼：坠落结构**深入地下**，污染自下向上蔓延，故名深渊。本区称此类存在为**渊魔**。同源跨区称呼见 [异魔](../../../../参与者/污染/异魔.md)（不写马尔斯研发与环带内战）。

**魔王**：地面人称异魔为渊魔或魔物，因而把统御异魔者称为魔王。马尔斯与法厄同都不称穿越机管理员为魔王。马尔斯侧若曾以宿主锚定等方式派出穿越机管理员，此人落地后成为当地集群的统御者时，只有地面用「魔王」称呼。细节见 [异魔](../../../../参与者/污染/异魔.md)。

**入：** 坠落而来。源在马尔斯轨道穿越机污染，不在地面另立源头。
