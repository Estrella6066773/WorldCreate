# 自缚之城

## 概述

- 极北岛上的与世隔绝之城；[执火者](../../../../../参与者/势力/执火者.md)革命后，屈服的城市人被 [昏昼](../../../../../参与者/人物/昏昼.md) 驱赶至此修建。
- 位于 [诸城所在之地](../README.md)边陲；连 [荒原人](../../../../../参与者/族群/荒原人.md) 都不愿涉足的险地之一。
- 主故事线：[城市与城邦](../../../../../../分支时间线/泰拉/地面/诸城所在之地/城市与城邦.md)（🟢 城市与城邦）。

---

## 故事时间轴（摘要）

### 执火者革命
- 残余众城市组成联邦与昏昼议和，内部倾轧后秘密泄露
- 昏昼踏平联邦各城，将屈服者放逐至极北岛，令其修建自缚之城
- 城市人退出世界舞台
