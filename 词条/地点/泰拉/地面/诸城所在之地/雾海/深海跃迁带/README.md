# 深海跃迁带

## 概述

- [雾海](../README.md)远海深处；以太浸染由「连续高背景值」向不可逆污染阈值**跃迁**的地带。
- 父级：[雾海](../README.md) · [诸城所在之地](../../README.md)

---

## 区位与性质

- **以太特征**：越向深海浸染越重；跃迁带为危险梯度最陡的区域
- **活动限制**：勘探与深入均极为困难；规模显著大于 [执火者旧占领区](../../执火者旧占领区/README.md) 的离散高浓区
- **海况**：异常涡旋与能见度骤降在深海更为频繁
