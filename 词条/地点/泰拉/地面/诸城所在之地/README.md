## 概述

- 本区是[泰拉地面](../README.md)上以城市、聚落与文明遗迹为主体的地表区域，与[城市与城邦](../../../../../分支时间线/泰拉/地面/诸城所在之地/城市与城邦.md)这条主线一致。故事地图常以陷落的前文明巨城 [塔罗瑞斯](./塔罗瑞斯/README.md) 遗址为方位参照。
- 主故事线：[城市与城邦](../../../../../分支时间线/泰拉/地面/诸城所在之地/城市与城邦.md)（🟢 城市与城邦）。
