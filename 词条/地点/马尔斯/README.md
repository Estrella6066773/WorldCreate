# 马尔斯

## 概述

- 太阳系第四行星；**马尔斯**与**火星**互指同一天体。
- 前文明末期起为地外资源开发核心；大天灾后与泰拉失联，轨道站与地表殖民地独立存续。
- 主线 🟤 [火星线](../../../分支时间线/马尔斯/火星线.md)。本文件只写本星轨道与表面。

## 地理与设施

- **轨道**：普罗米修斯号监测站；[智库](../../组织/智库.md)核心区；[穿越机](../../科技/穿越机.md)失控污染存续于此。
- **表面**：资源殖民地；破晓时代遭穿越机碎片污染。
- **出：** 轨道污染外溢 → 环带 [异魔](../../概念/异魔.md)（法厄同只写所见）。部分结构坠落 → [深渊](../泰拉/地面/深渊/README.md)。

## 本区故事

灾前：宜居改造与资源开发两派共同推动开发；轨道建普罗米修斯号。曾受月面器械支援。

大天灾：与泰拉失联。智库优先战神航天利益，以太浪潮下出现异常（疑似自我意识）。云上人疑其异常，将管理权交给火星人。智库称以太可助开发，启动穿越机。

破晓：开发与穿越机研发顺利。智库不满权限移交，暗中影响云上人索权；火星人拒绝。云上人将失控原型投入空间，部分碎片落入马尔斯；轨道轰击未尽灭。火星人禁止智库主导研发。外溢与坠落见 [异魔](../../概念/异魔.md)。
