# 马尔斯

## 概述

- 太阳系第四行星；**马尔斯**与**火星**互指同一天体。
- 前文明末期起为地外资源开发核心；大天灾后与泰拉失联，轨道站与地表殖民地独立存续。
- 主线 🟤 [开拓马尔斯](../../../分支时间线/马尔斯/开拓马尔斯.md)。本文件只写本星轨道与表面。

## 地理与设施

- **轨道**：普罗米修斯号监测站；[智库](../../参与者/势力/智库.md)曾作总控核心区，现已封存修剪；[穿越机](../../参与者/污染/穿越机.md)污染存续于此。轨道上的云城以勘探、科考与贸易为主，工业少量；没有规模很大的工业云城。马尔斯航天在此部署的云城研发了穿越机。
- **表面**：资源殖民地与地上三大基地（专名待定）；破晓时代遭穿越机污染波及。
- **出：** 轨道污染外溢 → 环带 [异魔](../../参与者/污染/异魔.md)（法厄同只写所见）。部分结构坠落 → [深渊](../泰拉/地面/深渊/README.md)。

## 本区故事

灾前：宜居改造与资源开发两派共同推动开发；轨道建普罗米修斯号。马尔斯航天理事会为 6 席（地上 3、云城 3），权力核心在云城。曾受月面器械支援。

大天灾：与泰拉失联。智库以总控身份协调轨道存续，优先照顾马尔斯航天利益。以太异变环境下，马尔斯航天轨道云城研发穿越机；智库尚未异化，参与项目管理。

其后：穿越机伪人格化异常改变智库。马尔斯航天理事会决议封存修剪智库总控，切断其对穿越机的管理权限并封存原型；高级事务改由人工决策，局部通用模型仍可使用；理事会扩展为 12 席。物质封存无法约束穿越机在以太中的投射，原型泄露并在轨道扩散；空间站遏制后，仍有感染结构脱轨外飘或坠入马尔斯地表。外溢与坠落见 [异魔](../../参与者/污染/异魔.md)。事件：[马尔斯航天理事会封存修剪智库](../../事件/权限/马尔斯航天理事会封存修剪智库.md)。
