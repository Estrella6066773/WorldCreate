# 云城

## 概述
- **中文定名：云城**；**英文定名：Cloud City**（复数：**Cloud Cities**）。
- **敲定口径：** 英文即「云城邦联／Confederation of Cloud Cities」里的那个 **Cloud City**——不作另译、不另造专名。
- 云城是云上人活动的云端节点。在[法厄同](法厄同/README.md)带上，各州由云城组成，多个云城依协议互联，构成[云邦](../参与者/势力/云邦.md)。泰拉、卢娜、马尔斯也可以有云城，但不因此属于云邦。
- 官方全称「云城邦联」／**Confederation of Cloud Cities**（缩写 **CCC**）仅指法厄同带上的云邦，由本带各州的 Cloud City 组成。

## 定名

| 层级 | 中文 | 英文 |
|------|------|------|
| 单元 | **云城** | **Cloud City**（＝ CCC 全称中的 Cloud City） |
| 复数／网络 | 云城（网络／节点） | **Cloud Cities** |
| 法厄同带协约体全称 | 云城邦联 | Confederation of Cloud Cities（CCC） |
| 法厄同带协约体简称 | 云邦 | Orbis |

### 用法
1. 设定文档、地图标注、英文对白中的单元名写 **Cloud City**。
2. 指法厄同带上组成云邦时，用复数 **Cloud Cities**（与 CCC 全称一致）。其它轨道的云城仍叫 Cloud City，但不因此属于云邦。
3. 不另造拉丁短名或其它英文别译——单元英文锁定为邦联全称中的 Cloud City。
4. 主体居民英文见 [云上人](../参与者/族群/云上人.md)＝**Cloudtype**。

## 性质与结构
- **技术底座**：依托云上技术与服务器阵列；节点间以云上亚区块链等协议协同。
- **主体居民**：[云上人](../参与者/族群/云上人.md)（Cloudtype）为管理与活动骨干。
- **人类起居**：早期仅供云上人；扩张后部分大型云城加入可供肉身人类起居的结构，权限仍低于云上人。
- **与空间站**：云城可外挂／联通空间站与轨道设施，但「云城」指云端政治—社会节点，不等于任一实体站体。

## 与其他概念
- **[云邦](../参与者/势力/云邦.md)**：仅法厄同带。由本带各州的云城组成的联合国式协约体（简称云邦／Orbis）。其它轨道的云城不归云邦管。
- **[云上坟场](../../分支时间线/法厄同/云上坟场/README.md)**：环带节点失联、碎片化与 A 站侧云城残部的微观叙述。
- **云世界**：云上人活动的云端总体；云城是其可治理、可点名的节点化形态。
- **服务器独立／碎片化**：大天灾后航道切断、节点失联，许多云城节点被迫各自运转。法厄同的内战见环带大战；近地如何重组后续再议。
