# 地球轨道服务器阵列

## 概述

- [地球轨道](../README.md)上为云世界提供基础设施的服务器阵列。
- 主故事线：[云上线](../../../../../分支时间线/云上线.md)（🟡 云上人空间站集群线）。

---

## 性质与关联

- **功能**：云邦云城网络的云端底座之一，支撑云上技术与云城节点运转。
- **建设**：前文明末期，云上技术落地后于地球轨道建立。
- **与研究站**：[轨道研究站](../轨道研究站/README.md)在总世界线中存在「主导」关系——研究站参与以太航行研发，并关联服务器阵列建设。

---

## 故事时间轴（摘要）

### 前文明末期
- 云城联邦协约签订前后，地球轨道建立服务器阵列
- 轨道研究站参与以太航行技术研发，技术应用于云世界太阳系扩张

### 大天灾
- 远程航道被以太乱流切断；云世界各区域受管辖程度降低
- 云世界管理层拒绝向轨道研究站提供援助

### 破晓时代
- 云上人改良以太航行技术，尝试重建航道；阵列仍为核心云端基础设施
