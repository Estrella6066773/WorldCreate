# 轨道研究站

## 概述

- [地球轨道](../README.md)上的以太研究空间站；规模宛如一座小镇，可不受补给独立运转数十年。
- 主故事线：[以太线](../../../../../分支时间线/以太线.md)（🟣 魔神线）；叙事上为魔神起源之地。

---

## 性质与建立

- **建立目的**：针对「大灾变」前兆设立的空间实验站，观测与大灾变相关的异象。
- **特点**：自给自足的研究设施，不同团队共用这一以太研究设施。
- **技术产出**：参与研发以太航行技术、以太壁垒技术；后者经壁垒协议落地，成为 [地面](../../地面/README.md) 节点城建设的核心技术基础。

---

## 故事时间轴（摘要）

### 前文明末期
- 前文明系统研究以太后建立轨道研究站
- 参与研发以太航行技术与以太壁垒技术

### 大天灾
- 资源断供、航道失效，无法物理脱困
- 向云上世界、月表、[马尔斯](../../../马尔斯/README.md)轨道求援均未果，陷入孤立
- 发现大天灾后以太性质异变；开展意识与以太关联实验（意识注入以太、转移至以太等）
- 哈达德在被困时期完成意识以太化，成为首个源质实体
