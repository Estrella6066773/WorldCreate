# 轨道研究站

## 概述

- [地球轨道](../README.md)上的以太研究空间站；规模宛如一座小镇，可不受补给独立运转数十年。
- 主故事线：[以太线](../../../../../分支时间线/以太线.md)（🟣 魔神线）；叙事上为魔神起源之地。

> 状态说明：以太线文档标注为「未敲定，仅 AI 整理」；本文档据现有分支时间线与关联词条归纳。

---

## 性质与建立

- **建立目的**：针对「大灾变」前兆设立的空间实验站，观测与大灾变相关的异象。
- **设施特点**：自给自足的研究设施，不同团队共用同一以太研究设施；以太存在于空间之中，其性质与后世所知不同。
- **防范措施**：对可能到来的危险有所预料，提前部署部分防范措施。
- **技术产出**：参与研发以太航行技术、以太壁垒技术；后者经壁垒协议落地，成为 [地面](../../地面/README.md) [节点城网络](../../地面/众城所在地/节点城网络/README.md) 建设的核心技术基础。
- **技术限制**：技术尚不成熟，且受保密协议约束，两项技术未广泛推广，仅少数相关团体了解。

---

## 跨故事线关联

- 与研究站研发相关的以太航行技术，后支撑矩阵联合云城网络的太阳系扩张（见 [地球轨道服务器阵列](../地球轨道服务器阵列/README.md)）；研究站在总世界线中对服务器阵列存在「主导」关系。
- 大天灾期间，[云上人](../../../../族群/云上人.md)管理层坚持「麦哲伦号」建设，拒绝向研究站提供援助；[马尔斯](../../../马尔斯/README.md)轨道因航道被异象切断、距离过远无法驰援。

---

## 故事时间轴（摘要）

### 前文明末期

- 前文明发现以太后，开展系统以太研究，并建立轨道研究站
- 不同团队参与研发以太航行技术与以太壁垒技术

### 大天灾

- 资源断供、航道失效，无法物理脱困
- 向云上世界管理层、月表器械、[马尔斯](../../../马尔斯/README.md)轨道求援均未果，陷入孤立
- 发现大天灾后以太性质异变；开展意识与以太关联实验（意识注入以太、转移至以太等）
- 环境中以太浓度提升至前所未有的高度，成为幸存者寻求出路的突破口
- 被困第 777 天，首席心理学家兼以太思维学家哈达德主动接受意识以太化实验，成为首个源质实体

### 破晓时代

- 哈达德作为源质实体坠入大气，意识随载体碎片散落后再于地表重新凝聚；此后以太线叙事转至 [地面](../../地面/README.md)（见 [以太线](../../../../../分支时间线/以太线.md)）
- 以太航行技术经云上人改良；研究站早期成果仍具参考价值
