# 世界树

## 概述

- [地球地面](../README.md)上离节点城市群极远的**被隔绝天国**所在地带；与外界长期隔绝。核心神木为**世界树**，[精灵](../../../../族群/精灵.md)赖以生存。
- 主故事线：[精灵线](../../../../../分支时间线/精灵线.md)（🔴 精灵线）。

---

## 别名

| 称谓 | 说明 |

| 祖树 | [精灵](../../../../族群/精灵.md)惯用别名，指同一神木与所在天国 |

---

## 区位与性质

- 与 [众城所在地](../众城所在地/README.md) 中的节点城网络均相距极远，属地面上的独立文化圈。
- 大天灾期间世界树（精灵称祖树）异变，精灵操控植物的能力被环境弱化；少数精灵逃离，其中的大部分不再遵从戒律。
- 逃离的精灵分支漂泊至 [众城所在地](../众城所在地/README.md)（含 [城邦](../众城所在地/城邦/README.md)、[东部荒原带](../众城所在地/东部荒原带/README.md)）后，与 [巴力](../../../../概念/巴力.md)及 [荒原人](../../../../族群/荒原人.md)建立关系。

---

## 故事时间轴（摘要）

### 前文明末期
- 被隔绝的天国形成；精灵特征确立（尖耳、淡色毛发、寿命悠长、能操纵植物）

### 大天灾
- 世界树异变（精灵称祖树异变）；植物异变，操控能力弱化
- 少数精灵逃离祖树，大部分不再遵从戒律；明知家乡灾情较地面轻，仍远行「投机」

### 破晓时代
- 逃离精灵与荒原人、巴力建立关系；部分成为巴力神殿侍从
