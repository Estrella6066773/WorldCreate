## 区位与性质

- **居民**：整体人种风貌近似小亚细亚诸族
- **气候**：沿海地中海气候，内陆高地过渡为大陆性干冷气候
- **交通**：自 [亚特兰](../亚特兰/README.md) 沿海岸线向东抵达港城带，再深入山城带与高原城带
