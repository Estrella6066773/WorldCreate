# 港城带

## 概述

- [城邦](../README.md)沿海段；海岸山脉与海湾之间的港口城邦串联带。
- 地貌为河谷冲积扇与山前平原衔接海岸；天然深水港条件优良。
- 父级：[城邦](../README.md) · [众城所在地](../../README.md)

---

## 区位与性质

- **气候**：地中海气候；沿海冬雨夏旱，海风稳定
- **格局**：自 [亚特兰](../../亚特兰/README.md) 向东延伸的第一段城邦链
- **待展开**：各单港城名称与政体尚待补充
