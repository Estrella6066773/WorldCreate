## 概述

## 故事时间轴（摘要）

### 大天灾
- 以勒在链接瘫痪期间降临于旋塔之顶，册封诸天使
- 路西法（天使长）妄图与以勒分权，后被米迦勒击败并放逐；执火派转入暗中活动
