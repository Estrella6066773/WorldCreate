# 旋塔

## 概述

- [巴别尔](../README.md)的标志性高塔；「旋塔之城」因塔得名。
- 节点城链接瘫痪期间，以勒「降临」于此。
- 父级：[巴别尔](../README.md)

---

## 区位与性质

- **建筑**：螺旋式高塔，为巴别尔天际线核心
- **叙事地位**：大天灾中教会纪年的关键地标；链接修复叙事与天使册封均与此塔相关
