# 腹中沉城

## 概述

- [塔罗瑞斯](../README.md)在大天灾中被**大地吞入腹中**的地下沉城遗迹；与 [地表遗址](../地表遗址/README.md) 同属陷落巨城，但主体没入地壳之下。
- 父级：[塔罗瑞斯](../README.md) · [众城所在地](../../README.md)

---

## 区位与性质

- **地貌表现**：地下城郭、被掩埋的街道与建筑群；亚地下（subterranean）废墟
- **陷落方式**：潮涌期「大洪水」与地变叠加，整城被吞入腹中，非单纯地表摧毁
- **活动限制**：深入勘探极为困难；以太浓度与结构不稳定区并存，具体可通达层级待补充
