# 地表遗址

## 概述

- [塔罗瑞斯](../README.md)陷落后仍暴露于地表的部分；故事地图建立方位感的**中心参照点**。
- 父级：[塔罗瑞斯](../README.md) · [众城所在地](../../README.md)

---

## 区位与性质

- **地貌表现**：大地震留下的陷落痕迹；建筑倒塌、地陷与都市废墟交织的前文明巨城残骸
- **功能**：幸存节点城与各方势力描述方位的共同基准（西北为 [节点城网络](../../节点城网络/README.md)，东为 [东部荒原带](../../东部荒原带/README.md) 等）
- **可达性**：地表部分可接近、可远眺，但废墟区危险且以太异变残留未完全消退
