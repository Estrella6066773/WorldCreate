# 节点城网络

## 概述

- [众城所在地](../README.md)西北—中部主体区；以 [塔罗瑞斯](../塔罗瑞斯/地表遗址/README.md) 地表遗址为参照位于其**西北**方向，为仍延续运作的节点城集群。
- 主故事线：[地面线](../../../../../../分支时间线/地面线.md)（🟢 地面线）。

---

## 区位与性质

- **居民**：[城市人](../../../../../族群/城市人.md)（内城人）、外城平民
- **技术**：[以太壁垒技术](../../../../../概念/以太.md)保护的节点城（Node-City）；节点城之间以**链接**锚定，稳定壁垒并传递资源与信息
- **信仰**：[伊勒](../../../../../概念/伊勒.md)信仰在节点城秩序中制度化
- **地貌**：宽谷平原、低山丘陵与密集河网；海洋性气候向温带大陆性气候过渡（近似西欧—中欧过渡带）
- **气候**：冬季湿冷，极少极端低温；夏季温和至偏暖；四季分明，年降水量分布较为均匀

---

## 故事时间轴（摘要）

### 前文明末期
- 壁垒协议制定；依托 [轨道研究站](../../../轨道/轨道研究站/README.md) 研发的以太壁垒技术启动节点城建设

### 大天灾
- 节点城断联，部分城市陷落；幸存节点城尝试修复链接
- 以勒「降临」于 [巴别尔](../巴别尔/旋塔/README.md)；于 [塔顶花园](../巴别尔/塔顶花园/README.md) 册封诸天使
- 诸天使指引修复链接
- 强迫外城平民于外界作业；链接修复后与 [荒原人](../../../../../族群/荒原人.md) 隔绝
- 城市人完全依赖城内供应链，以奴役荒原人获取外界资源

### 破晓时代
- [执火者](../../../../../阵营/执火者.md)革命后节点城逐渐陷落；残余城市组成联邦后溃败
