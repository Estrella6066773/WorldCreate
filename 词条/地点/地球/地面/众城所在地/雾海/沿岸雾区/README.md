# 沿岸雾区

## 概述

- [雾海](../README.md)近岸海域；与东南外海岸线相接的低能见度带。
- 父级：[雾海](../README.md) · [众城所在地](../../README.md)

---

## 区位与性质

- **海况**：冷暖气团交汇、低层逆温；漂移雾墙、异常潮汐与不稳定涡旋
- **岸线**：盐沼、黑沙滩、受侵蚀断崖
- **以太**：连续高背景值起步，较 [深海跃迁带](../深海跃迁带/README.md) 温和，但仍限制航行与勘探
