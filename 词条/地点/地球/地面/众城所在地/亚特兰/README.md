# 亚特兰

## 概述

- [众城所在地](../README.md)西南半岛上的滨海城市；自 [节点城网络](../节点城网络/README.md) 向西南沿海延伸的半岛顶端，**非节点城体系**。
- 主故事线：[地面线](../../../../../../分支时间线/地面线.md)（🟢 地面线 · 海潮派）。

---

## 区位与性质

- **派系**：伊勒信仰**海潮派**所建；主张「洪水即伊勒之力」，主要研究以太与「大洪水」
- **地貌**：石灰岩海岸、岬角与海湾密集；内陆丘陵梯田与低山盆地，具备优良天然深水港
- **气候**：以地中海气候为主，北段受海洋性气候调节；夏季炎热干燥，冬季温和多雨
- **交通**：沿半岛海岸线向东可抵达 [城邦](../城邦/README.md) 诸城，沿途仅遇零星边境节点城
