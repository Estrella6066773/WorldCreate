# 执火者旧占领区

## 概述

- [众城所在地](../README.md)东北部地带；以 [塔罗瑞斯](../塔罗瑞斯/README.md) 遗址为参照位于其**东北**方，历史上曾被 [执火者](../../../../../阵营/执火者.md) 占领。
- 主故事线：[地面线](../../../../../../分支时间线/地面线.md)（🟢 地面线）。

---

## 区位与性质

- **地貌**：针阔混交林、冰碛丘陵、泥炭沼地与破碎河湖系统
- **气候**：寒温带大陆性气候至亚寒带南缘；冬季严寒、积雪期长；春秋季短促；冻融循环强烈
- **以太特征**：多处离散型高浓度以太区（「冷斑」与「亮斑」），常沿断裂带、古战场及旧节点设施残骸分布；单体规模普遍小于 [雾海](../雾海/README.md)，但对行军与定居的扰动更为随机
