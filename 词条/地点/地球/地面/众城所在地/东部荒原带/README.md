# 东部荒原带

## 概述

- [众城所在地](../README.md)以东的广阔地带；以 [塔罗瑞斯](../塔罗瑞斯/README.md) 遗址为参照位于其**以东**，[荒原人](../../../../../族群/荒原人.md)广泛分布，其间夹着少数边境节点城或遗址（含 [巴别尔](../巴别尔/README.md)）。
- 主故事线：[地面线](../../../../../../分支时间线/地面线.md)（🟢 地面线）。

---

## 区位与性质

- **居民**：[荒原人](../../../../../族群/荒原人.md)；荒原聚落亦称城邦（The Enclaves），与 [城邦](../城邦/README.md) 所指哈达德众城邦不同
- **地貌**：黑土草原、风蚀台地、季节性河谷与盐碱洼地；局部次生荒漠化地表
- **气候**：温带大陆性至半干旱草原气候；冬季更冷更干，夏季更热，气温年较差显著；旱涝年际变化剧烈

---

## 故事时间轴（摘要）

### 大天灾后
- 外城平民长期暴露外界，部分异变并入荒原群体；城市人修复链接后与荒原人隔绝
- 城市人对荒原人隔离、驱散、奴役与清剿；荒原人中强大 [天赋者](../../../../../族群/天赋者.md) 常遭扼杀

### 破晓时代
- [昏昼](../../../../../人物/昏昼.md)与织星者带领 [执火者](../../../../../阵营/执火者.md) 击溃城市联邦
- 城邦（The Enclaves）说法出现于节点城陷落末期；荒原人得以建立大型聚落
