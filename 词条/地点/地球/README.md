# 地球

## 概述

- 人类文明的母星，太阳系第三行星；叙事中地表活动与地球轨道设施分属多条故事线交汇的舞台。
- 下设两大子类：**[轨道](./轨道/README.md)**（云上线、以太线等太空基建）与 **[地面](./地面/README.md)**（地面线为主轴的地表叙事）。
- 地面分为 **[世界树](./地面/世界树/README.md)** 与 **[众城所在地](./地面/众城所在地/README.md)**（含节点城网络、荒原、亚特兰、雾海、城邦等子词条，见该目录子区索引）。

> 本文档据 `分支时间线/` 与既有词条归纳；子区详情见各子文件夹 README。

## 跨故事线关联

### 与云上线 / 以太线
- 轨道侧服务器阵列与研究站分别支撑云世界与以太技术研发；详见 [轨道](./轨道/README.md)

### 与地面线 / 精灵线
- [众城所在地](./地面/众城所在地/README.md)与 [世界树](./地面/世界树/README.md) 分属地面两大区

### 与火星线 / 法厄同 / 月球线
- 大灾后马尔斯轨道与地球主世界失联；法厄同、马尔斯与地球轨道云城网络存在航运关联；月表向云世界与马尔斯轨道提供器械支持
