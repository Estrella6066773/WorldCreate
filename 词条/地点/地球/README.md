# 地球

## 概述

- 人类文明的母星，太阳系第三行星；叙事中地表活动与地球轨道设施分属多条故事线交汇的舞台。
- 下设两大子类：**[轨道](./轨道/README.md)**（以太线、云上线基建）与 **[地面](./地面/README.md)**（地面线／精灵线）。地面另含 **[深渊](./地面/深渊/README.md)**（渊魔坠落区）。
- 本文件只作地球分层索引；各子区写各子区故事。

> 本文档据 `分支时间线/` 与既有词条归纳；子区详情见各子文件夹 README。
