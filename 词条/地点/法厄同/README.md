# 法厄同

## 概述

- 太阳系小行星带；亦称**法厄同环**、**法厄同带**、**法厄同之环**。派生项目 SpaceShip 称**环带**，已确认为同一地点。
- [云邦](../../阵营/云邦.md)云城网络向外行星圈延伸的前沿布点。主线 🟡 [云上线](../../../分支时间线/法厄同/云上线.md)。本文件只写本带所见。
- 与 [马尔斯](../马尔斯/README.md) 分属不同轨道，相距以天文单位计。版图上马尔斯是其内侧最近的大行星，不是贴邻或同一活动区。

> 麦哲伦号航路与环带核心区已按云上线改写。环带战场、残骸区与 A 站作业见 [云上坟场](../../../分支时间线/法厄同/云上坟场/README.md)。

## 本区故事

灾前：云邦在此布点；[云上人](../../族群/云上人.md)任航班司机、监测站管理员。曾受月面器械支援（不写月面内部）。麦哲伦号建造与出航见[云上线](../../../分支时间线/法厄同/云上线.md)；本带与麦哲伦号没有从属关系。

**环带核心区**：本带最大铀矿矿区、工业相对发达的区域。不是整个太阳系的核心。

大天灾：航道切断、远距通讯失效，本带与外界失去联系。麦哲伦号按预定航路从旁高速经过（不减速、不进入港口停泊），送来失联以来第一份来自外界的消息：其他地区亦遭波及、损失惨重，但细节不明、不响应远距通讯。其后环带核心区的云城势力组成政治团体，试图把松散的云城邦联改组为战时政权，对整条环带实行统一管辖；边陲矿主不满，组成 [矿业联盟](../../阵营/矿业联盟.md)，爆发**环带大战**。战场遍及本带。环带核心区握有最大铀矿与反应堆链，无力收复失地；战后联盟控制大片区域，废墟打捞成为空间站生计。

破晓：锚点航行开始修复本带航道。[异魔](../../概念/异魔.md)自马尔斯轨道外溢进入（源在马尔斯）。亚冷战未结束时，外溢可迫使各方休战（派生击魄，不展开马尔斯权限斗争）。

## 跨区接口

| 方向 | 内容 |
|------|------|
| 入（灾前） | 云邦布点；月面器械支援 |
| 出／入（大天灾） | 航道切断、远距失联；不展开泰拉或马尔斯内部 |
| 入（大天灾） | 麦哲伦号从旁高速经过并送出消息（不进入港口停泊；近距通讯可用，可派遣使者）；不展开舰内 |
| 入（破晓） | 异魔外溢（源见 [马尔斯](../马尔斯/README.md)） |
| 微观 | [云上坟场](../../../分支时间线/法厄同/云上坟场/README.md) |
