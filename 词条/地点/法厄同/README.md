# 法厄同

## 概述
- 太阳系内的小行星带，叙事中亦称**法厄同环**、**法厄同带**、**法厄同之环**。
- 属于[云上人](../../族群/云上人.md)世界线（[云上线](../../../分支时间线/云上线.md)）的太空活动区域，是[云邦](../../阵营/云邦.md)云城网络向外行星圈延伸的前沿布点地带之一。
- 主故事线为 🟡 **云上线**（云上人空间站集群线），并与月球线、以太线、火星线存在交叉。

法厄同与[马尔斯](../马尔斯/README.md)是**两个独立地点**：法厄同归属云上线，马尔斯归属火星线；叙事主线各自独立。二者在太阳系版图上位置参照相近（见下文「地理关系」），但并非同一轨道区域。

## 地理关系

法厄同是太阳系内的小行星带，与马尔斯（火星）**分属不同轨道区域**，相距仍以天文单位计。

所谓「临近」，是**相对于整个太阳系的天体分布**而言——参照现实中主小行星带与火星的关系：在太阳系版图上，马尔斯是法厄同带内侧最近的主要行星，但不宜理解为轨道毗邻、贴身相邻或同一活动区。云邦向此带布点，是因这里处于外行星圈入口一带，而非因为法厄同与马尔斯共用轨道。

## 故事时间轴

以下事件来自云上线，与法厄同区域直接相关或在其地理范围内展开。

### 第一阶段：前文明末期

#### 1. 云上技术出现与云城联邦协约
云上技术落地，地上各国共建[云邦](../../阵营/云邦.md)（全称云城联邦），为太阳系内云城网络扩张奠定协约基础。法厄同带作为外行星圈入口一带的布点区域，纳入云邦的太空探索版图。

#### 2. 地球轨道服务器阵列
地球轨道建立服务器阵列，为云世界提供基础设施。法厄同带的监测站与航运节点依托这一云端底座运转。

#### 3. 云邦云城扩张
云邦的云城网络在太阳系内扩张，搭建空间站，收到月表器械支持。[云上人](../../族群/云上人.md)构成多样，需靠资源维系存续，一般担任**空间航班的司机**或**空间监测站的管理员**——法厄同带是此类岗位最密集的前沿区域之一。

云上人传输受以太干扰，无法远距离传输意识；在太空空间层面的活动中与肉身人类区别不大。法厄同作为云邦向外行星圈延伸的前沿布点，云上人须以航天器往来，在此布设监测站与航运节点。

#### 4. 「麦哲伦号」开始施工
麦哲伦号施工启动，备受争议。法厄同带与太阳系内其他云城节点一样，受到云邦整体扩张与资源调配的影响；云上人劳动力在太阳系各布点间流动，法厄同为其中一环。

---

### 第二阶段：大天灾

#### 5. 云世界遭受严重影响
远程航道被以太乱流切断，各区域受管辖程度大幅降低。法厄同带的航运节点与监测站同样陷入与云邦核心失联或弱联系的状态。

#### 6. 管理层坚持建设「麦哲伦号」
云世界管理层坚持麦哲伦号建设，拒绝向轨道研究站等方提供援助。法厄同作为边缘前沿地带，资源与指令优先级进一步边缘化。

#### 7–9. 叛乱与云邦碎片化
部分分机叛乱，意图夺取麦哲伦号；叛乱失败但许多服务器独立，云邦分裂为大量碎片节点，内战态势类似「南北战争」。法厄同带的云城节点可能随整体碎片化而独立或重组，具体节点归属待定。

---

### 第三阶段：破晓时代

#### 10. 改良以太航行技术
云上人改良以太航行技术：通过投放锚点锚定目标，在结界庇护下航行；无法前往没有锚点的地点。云上人作为数据资产，底层协议禁止直接跨空间传输，须借特制航天器往来；同一轨道内短距离定向传输仍被允许。

法厄同带的航运重建依赖锚点布设与结界航道，是破晓时代云邦尝试恢复太阳系交通的关键节点之一。

#### 11. 开始重建部分航道
利用改良的以太航行技术，开始重建部分被切断的航道。法厄同作为中继地带，参与连接地球轨道云城网络与外围布点的航道修复。

#### 12. 未完待续

## 关键转折点

1. **云邦云城扩张** — 法厄同纳入太阳系布点网络，成为外行星圈前沿布点
2. **航道被切断** — 大天灾导致法厄同与核心云城弱联系或失联
3. **云邦碎片化** — 叛乱与大天灾使法厄同所在节点可能独立
4. **技术改良** — 锚点以太航行为法厄同航道重建提供可能

---

## 核心冲突

| 冲突 | 要点 |
|------|------|
| 资源需求 | 云上人须工作维系存续，法厄同监测站与航运岗位是主要生计来源之一 |
| 传输限制 | 禁止跨空间意识传输，法厄同活动依赖航天器与轨道内短距传输 |
| 航道危机 | 大天灾切断远程航道，法厄同中继功能受阻 |
| 世界碎片化 | 云邦分裂，法厄同节点归属与管辖待明确 |
| 锚点限制 | 改良航行技术无法抵达无锚点区域，制约法厄同对外联通 |

## 跨故事线关联

### 与马尔斯（火星线）
- 太阳系版图上，马尔斯是法厄同带内侧最近的主要行星；二者分属不同轨道区域，相距以天文单位计（详见[地理关系](#地理关系)）

- 云上人曾拥有智库管理权限后转移给火星人——此事件属火星线，与法厄同无直接叙事关联

### 与月球线
- 法厄同带扩张收到月表器械支持
- 织机引擎在月球与木星间测试，与云上线麦哲伦号建设同期

### 与以太线
- 改良以太航行技术可能参考轨道研究站研究
- 大天灾中云世界管理层拒绝向轨道研究站提供帮助
