# 法厄同

## 概述

- 太阳系小行星带；亦称**法厄同环**、**法厄同带**、**法厄同之环**。派生项目 SpaceShip 称**环带**，已确认为同一地点。
- [云邦](../../参与者/势力/云邦.md)只存在于本带：环带上的联合国式协约体。基本单位是成员。州是成员的一种，地上国的附属机构也可以作为成员。主线 🟡 [环带前史](../../../分支时间线/法厄同/环带前史.md)。本文件只写本带所见。
- 与 [马尔斯](../马尔斯/README.md) 分属不同轨道，相距以天文单位计。版图上马尔斯是其内侧最近的大行星，不是贴邻或同一活动区。

> 麦哲伦号不是云邦的船。环带战场、残骸区与 A 站作业见 [云上坟场](../../../分支时间线/法厄同/云上坟场/README.md)。亚冷战之后、休战组成的反异魔阵线见 [击魄](../../../分支时间线/法厄同/击魄/README.md)。

## 本区故事

灾前：三家地上主要势力在此落下三片最初据点，即三个创始州，合称**核心区**。东亚合作社已经定名，欧亚国同盟与大洋州联邦两个名字仍待定。它们组成云邦。[云上人](../../参与者/族群/云上人.md)任航班司机、监测站管理员。月面向本带输出器械（月球工业基地是东亚合作社的手笔；不写月面内部）。这家合作社也创建并推广分发额度的底层超级智能。最大铀矿在东亚合作社那一创始州附近。偏远、还在开发的地带称**边缘区**（定界不画死）。尚未成州的拓荒地称**领地**。领地不是云邦的成员。麦哲伦号建造与出航见[环带前史](../../../分支时间线/法厄同/环带前史.md)；本带与麦哲伦号没有从属关系。

大天灾：航道切断、远距通讯失效，本带与外界失去联系。大天灾之前，地方势力已经不满意云邦的干涉，因忌惮地上的宗主势力介入而行动收敛。失联之后，他们不再听从云邦。跨越真空的抛物线航行不能再用，船贴着小行星带绕行，这些地段被矿主圈占。麦哲伦号按预定航路从旁高速经过（不减速、不进入港口停泊），送来失联以来第一份来自外界的消息：其他地区亦遭波及、损失惨重，但细节不明、不响应远距通讯。主要是核心区派得上使者。核心区处理这份消息时过于忽视边缘区意见；随后希望把已经分散到各州和领地的权力收回，集中调度，以云邦会议的名义把协约体改组为战时政权。边缘区势力结成 [矿业联盟](../../参与者/势力/矿业联盟.md) 并独立，爆发**环带大战**。战场遍及本带。战后联盟控制大片区域，废墟打捞成为空间站生计。

破晓：锚点航行开始修复本带航道。[异魔](../../参与者/污染/异魔.md)自马尔斯轨道外溢进入（源在马尔斯）。亚冷战尚未正式停战；外溢迫使云城邦联与矿业联盟宣布休战。派生 [击魄](../../../分支时间线/法厄同/击魄/README.md) 写休战之后、反异魔阵线已经组成的那段时期，不展开马尔斯权限斗争。

| 入（灾前） | 三家地上势力落脚；月面向本带输出器械 |
| 出／入（大天灾） | 航道切断、远距失联；不展开泰拉或马尔斯内部 |
