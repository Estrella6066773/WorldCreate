# 法厄同

## 概述
- 太阳系内的小行星带，叙事中亦称**法厄同环**、**法厄同带**、**法厄同之环**。
- 属于[云上人](../../族群/云上人.md)世界线（[云上线](../../../分支时间线/法厄同/云上线.md)）的太空活动区域，是[云邦](../../阵营/云邦.md)云城网络向外行星圈延伸的前沿布点地带之一。
- 主故事线为 🟡 **云上线**。本文件只写**本带所见**；跨区只留接口，不抄马尔斯／泰拉／卢娜内部剧情。

法厄同与[马尔斯](../马尔斯/README.md)是**两个独立地点**：法厄同归属云上线，马尔斯归属火星线；叙事主线各自独立。二者在太阳系版图上位置参照相近（见下文「地理关系」），但并非同一轨道区域。

## 地理关系

法厄同是太阳系内的小行星带，与马尔斯（火星）**分属不同轨道区域**，相距仍以天文单位计。

所谓「临近」，是**相对于整个太阳系的天体分布**而言——参照现实中主小行星带与火星的关系：在太阳系版图上，马尔斯是法厄同带内侧最近的主要行星，但不宜理解为轨道毗邻、贴身相邻或同一活动区。云邦向此带布点，是因这里处于外行星圈入口一带，而非因为法厄同与马尔斯共用轨道。

## 位置与性质

- **天体区位**：太阳系小行星带；太阳系尺度上距马尔斯较近，但轨道区域独立（详见上文「地理关系」）。
- **活动主体**：以[云上人](../../族群/云上人.md)为主，依托云邦的太空探索协约开展运营与建设。
- **功能定位**：云邦云城网络向外行星圈延伸的前沿布点；云上人常在此担任空间航班司机、空间监测站管理员等职务。

## 主要势力

- **[云邦](../../阵营/云邦.md)**：云城网络在太阳系布点的重要节点区域；大天灾后近地派武装接管政权，曾尝试武装接管环带要地。
- **[矿业联盟](../../阵营/矿业联盟.md)**：大天灾后脱离云邦的矿主联盟，环带大战（环带内战）参战方；战后控制环带大片区域。
- **[云上人](../../族群/云上人.md)**：主体运营者，通过工作维系云上存续。

## 故事时间轴（本区）

云上技术起源、泰拉轨道服务器、麦哲伦号与近地叛乱，见[云上线](../../../分支时间线/法厄同/云上线.md)，不在本区展开。

### 前文明末期
云邦将本带纳入外行星圈前沿布点。监测站与航运节点在此运转；[云上人](../../族群/云上人.md)在本带担任空间航班司机、监测站管理员。灾前曾受月面器械支援（接口，不写月面内部）。

### 大天灾
航道切断，与云邦核心失联。环带原有商业瓦解。

**环带大战（本区主戏）**：云邦近地派武装接管要地；矿主抵抗并组成[矿业联盟](../../阵营/矿业联盟.md)。战场遍及本带，留下废墟。云邦无力收复；战后矿业联盟控制大片区域，废墟打捞成为空间站生计。微观见[云上坟场](../../../云上坟场/README.md)。

> 大战落在大天灾阶段（云邦碎片化之后），战后格局延续至破晓早期；起止年份待细化。

### 破晓时代
锚点航行开始修复本带航道。[异魔](../../概念/异魔.md)自马尔斯轨道外溢进入本区（源在马尔斯，本区只写所见）。亚冷战未结束时，外溢可迫使各方休战（派生击魄；不在此展开马尔斯权限斗争）。

## 关键转折点

1. **纳入布点** — 本带成为云邦外行星圈前沿
2. **失联** — 大天灾切断与核心云城的航道
3. **环带大战** — 云邦与矿业联盟在本带交战，化作废墟
4. **异魔进入** — 马尔斯轨道污染外溢，本区开始所见
