# 法厄同

## 概述

- 太阳系小行星带；亦称**法厄同环**、**法厄同带**、**法厄同之环**。派生项目 SpaceShip 称**环带**，已确认为同一地点。
- [云邦](../../阵营/云邦.md)云城网络向外行星圈延伸的前沿布点。主线 🟡 [云上线](../../../分支时间线/法厄同/云上线.md)。本文件只写本带所见。
- 与 [马尔斯](../马尔斯/README.md) 分属不同轨道，相距以天文单位计。版图上马尔斯是其内侧最近的大行星，不是贴邻或同一活动区。

> 云上线标注「未敲定，仅 AI 整理」。环带战场、残骸区与 A 站作业见 [云上坟场](../../../分支时间线/法厄同/云上坟场/README.md)。

## 本区故事

灾前：云邦在此布点；[云上人](../../族群/云上人.md)任航班司机、监测站管理员。曾受月面器械支援（不写月面内部）。近地起源、麦哲伦号与叛乱见云上线。

大天灾：航道切断，与云邦核心失联。近地派武装接管要地；矿主组成 [矿业联盟](../../阵营/矿业联盟.md)，爆发**环带大战**。战场遍及本带。云邦握最大铀矿与反应堆链，无力收复；战后联盟控制大片区域，废墟打捞成为空间站生计。

破晓：锚点航行开始修复本带航道。[异魔](../../概念/异魔.md)自马尔斯轨道外溢进入（源在马尔斯）。亚冷战未结束时，外溢可迫使各方休战（派生击魄，不展开马尔斯权限斗争）。
