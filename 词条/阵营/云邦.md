# 云邦

## 概述
- **简称：云邦**／**Orbis**；**全称：云城邦联**／**Confederation of Cloud Cities**（缩写 **CCC**）；旧称「矩阵联合」。
- 云上技术出现并初步实践后，各势力先各自建立云城，再为规范并共同促进太阳系内太空探索而组成的协约体，性质类似「联合国 + 多服务器邦联」——官方全称即写明：邦联由各势力的 **[云城](../概念/云城.md)**（**Cloud City**，即 CCC 全称中的 Cloud City）节点加盟组成；主体族群为 **[云上人](../族群/云上人.md)**（**Cloudtype**）。
- 各国／派系提供云城节点，采用云上亚区块链技术协同治理，形成分布式、松散自治的云端政治实体。主权在各云城，中央是协约与互操作协议，不是单一帝国。
- 早期云城仅供云上人活动；随扩张，部分大型云城加入可供人类起居的结构，但人类的自由度与权限低于云上人。

### 用法
1. 叙述默认：**云邦**／**Orbis**。
2. 法统口气（授权、条约、宣战、禁令）：**云城邦联**／**Confederation of Cloud Cities**，可括注简称或 CCC。
3. 词条首次出现建议写：**云邦**（全称：**云城邦联**；Orbis，全称 Confederation of Cloud Cities，缩写 CCC）。

## 治理与结构
- **协约体／邦联属性**：各势力云城加盟，强调规则与互操作协议；核心目标是太空探索与云端拓展。
- **技术底座**：云上亚区块链 + 分布式服务器阵列；共识驱动的治理与权限分配。
- **组成单元**：[云城](../概念/云城.md)节点（不同国家／派系部署），可并行自治，依协议互联。
- **人口构成**：
  - [云上人](../族群/云上人.md)（Cloudtype）：主体与管理骨干，掌握高权限。
  - 人类（肉身）：在少数大型云城中可起居，但权限／自由度低于云上人。

## 历史脉络
- **起源**：云上技术先行落地后，各势力已有各自的云城；随后签订协约，组成云城邦联（简称云邦）以标准化规则、共用云城网络。
- **扩张**：云城在太阳系内布点，接受月面器械支持，推动“麦哲伦号”等大型工程。麦哲伦号在卢娜建造，转入泰拉轨道完成政治出航后离开；与法厄同没有从属关系。
- **各轨道产业**：泰拉轨道与马尔斯轨道没有规模很大的工业云城，以驿站、服务、观光与少量轻工业为主；卢娜为灾前工业中心；马尔斯仍在开发，云城多为勘探科考与贸易。太阳系云邦没有全系「核心区」这一中枢。
- **环带核心区**：专指[法厄同](../地点/法厄同/README.md)带内、建在最大铀矿矿区、工业相对发达的区域，不是整个太阳系的核心。
- **大天灾阶段**：以太航道失效、远距通讯中断，各区失联。麦哲伦号在赴木星途中、抵达法厄同之前遭遇大天灾，其后飞掠法厄同，送来失联以来第一份外界消息（不停泊、近距可通讯、可派使者）。近地如何碎片化后续再议。
  - **环带核心区收权**：悲报落地后，环带核心区的云城势力组成政治团体，试图把松散邦联收成战时政权，强化对整条环带的管辖（不是对整个太阳系 Orbis 发令）。
  - **环带大战（环带内战）**：边陲矿主对此不满，拒绝配合并武装抵抗，组成[矿业联盟](矿业联盟.md)，双方爆发环带内战（派生项目 SpaceShip 中称「环带大战」）。环带核心区虽持有带内规模最大的铀矿矿源与配套反应堆产业链，但战备与资源严重不足，战后无力发起远征、收复失地；大量原料产地宣告独立。
- **破晓时代**：在改良以太航行技术与锚点体系下，尝试重建航道与治理秩序。

## 与其他势力/设施
- **战神航天（马尔斯航天）**：雇佣大量云上人，也受云邦早期规则影响。
- **麦哲伦号**：云邦/云上线的旗舰工程之一；卢娜建造、泰拉轨道出航。与法厄同没有从属关系。
- **[智库](../组织/智库.md)**：曾由云上人/云邦授权管理，异常后权限转移给火星人。
- **[矿业联盟](矿业联盟.md)**：大天灾后脱离云邦的矿主联盟，环带大战（环带内战）的对立方。
- **巨企**：云邦体系内存在大型企业（派生项目剧情中特指「巨企N」）；环带大战中巨企损失惨重，但战后仍是大势力，控制相当规模的管辖区。
- **[云上坟场](../../分支时间线/法厄同/云上坟场/README.md)**：环带内战、授权断供与战后无力远征的微观叙述；暗线词条见 [云邦（子设定）](../../分支时间线/法厄同/云上坟场/02-暗线/02-势力/云邦.md)。

## 云上人创建授权
云邦对云上人的创建负有**官方授权**职责——思维上传须符合规范并获云邦授权方可认定为合法云上人，授权即合法性来源（详见[云上人](../族群/云上人.md)）。大天灾后远距数据传输被以太乱流切断，合法转化服务无法跨轨道维持。法厄同带内，边陲矿区失去合法授权通道。
