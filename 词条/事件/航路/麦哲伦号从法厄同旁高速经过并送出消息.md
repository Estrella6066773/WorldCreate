# 麦哲伦号从法厄同旁高速经过并送出消息

## 概述

麦哲伦号是泰拉体系的远航工程，不是云邦的船。大天灾中，它按预定航路从 [法厄同](../../地点/法厄同/README.md) 旁高速经过，不减速、不进入港口停泊，向已经与外界失联的环带送出第一份来自外界的消息。麦哲伦号与法厄同地区没有从属关系。

## 过程

1. 舰体在卢娜建造，从泰拉轨道出航，赴木星途中遭遇大天灾。
2. 按预定航路从法厄同旁经过，保持进入木星引力弹弓所需的速度。
3. 远距通讯已失效，近距通讯仍可用；航路附近的州可派遣使者。主要是核心区派得上使者。
4. 环带此后如何处理这份消息，见 [环带前史](../../../分支时间线/法厄同/环带前史.md)。不展开舰内。
