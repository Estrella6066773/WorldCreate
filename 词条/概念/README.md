# 概念

本层只留跨故事的抽象概念。被单个故事使用的概念放在该故事的 `词条/` 下，例如 [环带前史的概念](../../分支时间线/法厄同/词条/README.md)。

| 概念 | 归属 | 说明 |
|------|------|------|
| 信息海 | [环带前史](../../分支时间线/法厄同/词条/概念/信息海.md) | 旧文明构想的世界底层中只有信息、由规则施加影响的纯粹维度 |
| 云上世界 | [环带前史](../../分支时间线/法厄同/词条/概念/云上世界.md) | 旧文明在电子设备上搭建的虚拟网络空间，按云城分区 |
