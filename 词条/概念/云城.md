# 云城

## 概述
- **中文定名：云城**；**英文定名：Cloud City**（复数：**Cloud Cities**）。
- **敲定口径：** 英文即「云城联邦／Federation of Cloud Cities」里的那个 **Cloud City**——不作另译、不另造专名。
- 云邦／云城联邦的基本治理与活动单元——各国／派系部署的云端节点；多个云城依协议互联，构成联邦。
- 官方全称「云城联邦」／**Federation of Cloud Cities**（缩写 **FCC**）即由本单元复数组成：联邦＝云城之联邦。

## 定名

| 层级 | 中文 | 英文 |
|------|------|------|
| 单元 | **云城** | **Cloud City**（＝ FCC 全称中的 Cloud City） |
| 复数／网络 | 云城（网络／节点） | **Cloud Cities** |
| 所属联邦全称 | 云城联邦 | Federation of Cloud Cities（FCC） |
| 所属联邦简称 | 云邦 | Orbis |

### 用法
1. 设定文档、地图标注、英文对白中的单元名写 **Cloud City**。
2. 指网络或联邦组成时用复数 **Cloud Cities**（与 FCC 全称一致）。
3. 不另造拉丁短名或其它英文别译——单元英文锁定为联邦全称中的 Cloud City。
4. 主体居民英文见 [云上人](../族群/云上人.md)＝**Cloudtype**。

## 性质与结构
- **技术底座**：依托云上技术与服务器阵列；节点间以云上亚区块链等协议协同。
- **主体居民**：[云上人](../族群/云上人.md)（Cloudtype）为管理与活动骨干。
- **人类起居**：早期仅供云上人；扩张后部分大型云城加入可供肉身人类起居的结构，权限仍低于云上人。
- **与空间站**：云城可外挂／联通空间站与轨道设施，但「云城」指云端政治—社会节点，不等于任一实体站体。

## 与其他概念
- **[云邦](../阵营/云邦.md)**：由云城加盟组成的联邦政权（简称云邦／Orbis）。
- **云世界**：云上人活动的云端总体；云城是其可治理、可点名的节点化形态。
- **服务器独立／碎片化**：大天灾与叛乱中，许多服务器／云城节点独立或重组，联邦陷入内战态势。
