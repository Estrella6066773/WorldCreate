# 云上人

## 概述
- **中文定名：云上人**；**英文定名：Cloudtype**（复数：**Cloudtypes**；词形为连续一词 cloudtype，不作 Cloud Type／Cloud Person）。
- 人类的一个分支，最早依托云上技术将意识上传，成为[云邦](../阵营/云邦.md)的主体与管理骨干。
- 起居与工作主要在[云城](../概念/云城.md)（Cloud City；云邦节点）与轨道设施中，身份介于“数据公民”与“远程操作员”。
- 与肉身人类相比，拥有更高的权限与自由度；旧时代云城中少量保留肉身的人类自由度低于云上人。

| 层级 | 中文 | 英文 |

### 用法
1. 英文文案、双语场合写 **Cloudtype**；复数 **Cloudtypes**。  
2. 不译作 Cloud Person／Cloud Human／Uploader 等——正式定名以 Cloudtype 为准。  
3. 与政权／地点英文并置时：Cloudtype（人）· Cloud City（城）· Orbis／Federation of Cloud Cities（邦）。

## 形成与构成
- **技术前提**：云上技术（意识上传 + 云上亚区块链治理）先行落地后形成群体。
- **构成人群**：
  - 追求摆脱寿命限制的精英
  - 渴望摆脱残缺躯壳的病患
  - 贪恋权势财富的庸才
- **存续方式**：需资源维系计算与载体；上传仅保留学识/记忆/习惯，不保留肉体。

## 角色与权限
- 在[云邦](../阵营/云邦.md)中担任管理、运营与技术岗位，是云端政体的权力主体。
- 在战神航天（马尔斯航天）等机构中大量任职。
- 传输限制：以太干扰使远距离意识传输不可行，跨星体多依赖航天器；同轨道短距定向传输可行。

## 历史脉络
- **前文明末期**：云上技术出现并初步实践，云上人群形成；云城联邦协约其后建立。
- **扩张期**：随云城/云世界在太阳系布点，承担运营与建设。
- **大天灾**：以太航行失效、云世界碎片化，云邦陷入内战；云上人内部派系分裂，仍保持对智库等设施的关键权限（后移交火星人）。
- **破晓时代**：在改良以太航行与锚点体系下尝试重建航道与秩序。

## 与其他势力/技术
- **[云邦](../阵营/云邦.md)**：云上人是协约体主体与主要管理层。
- **[云城](../概念/云城.md)**：云上人主要活动与治理单元（Cloud City）。
- **[智库](../组织/智库.md)**：曾由云上人/云邦授权管理，后因异常被转移权限给火星人。
- **战神航天**：大量云上人员工。
- **麦哲伦号**：云邦旗舰工程之一，云上人主导建设。
- **[法厄同](../地点/法厄同/README.md)**：太阳系小行星带（云上线）；版图上距马尔斯较近，云上人常在此担任空间航班司机、监测站管理员等职务。
- **[云上坟场](../../云上坟场/README.md)**：云上人专属子设定集（法厄同环／A 站视角，自 SpaceShip 设定树迁入）。环带微观、明暗双轨与身份光谱以该集为细节权威。
