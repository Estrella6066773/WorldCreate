# 词条

母设定的细节权威源。按四条存储轴存放，与子设定集（击魄）同一套切法。导读见 [00-总览](../00-总览/README.md)。区域故事正文仍在 [分支时间线](../分支时间线/README.md)；跨区接口见 [总世界线](../总世界线.md)。

| 线 | 只存 | 不存 |
|----|------|------|
| [时间](时间/README.md) | 时代先后；法厄同按五段记 | 谁做了什么的过程 |
| [地点](地点/README.md) | 天体、地表、轨道、以太界、云城 | 在该处发生的事件全文 |
| [参与者](参与者/README.md) | 能作主语的一方：族群、势力、人物、污染、神与至高存在、机魂 | 事件因果链 |
| [事件](事件/README.md) | 跨区的「谁对谁做了什么」 | 把履历或地理志写进事件 |
| [概念](概念/README.md) | 跨线使用的抽象概念：世界构造、智能形态、因果机制 | 不把具体地点或事件写进概念 |

四条线内部可以再分，不必摊平。地点按空间嵌套（一处一个文件夹）；参与者按族群／势力／人物／污染／至高存在；概念单独存放跨线使用的抽象术语。各区细目不对齐到同一张总表。
