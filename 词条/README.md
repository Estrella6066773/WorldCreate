# 词条

跨故事层的入口。单个故事的词条放在该故事目录下的 `词条/`。导读见 [00-总览](../00-总览/README.md)；故事正文见 [分支时间线](../分支时间线/README.md)；跨区接口见 [总世界线](../总世界线.md)。

## 一条规则：一个事实，一篇权威

- 同一件事只写一遍，放在它所属的故事里；别处只链，不抄。
- 同一事物在不同故事里事实不同，就各写一篇，各管自己那一段。
- 各故事之间只认接口，不搬对方内部经过。

例：[异魔](参与者/污染/异魔.md) 在本层只是一篇接口页，列出四个故事各自的权威；起源写在 [马尔斯](../分支时间线/马尔斯/词条/参与者/势力/异魔.md)，环带所见写在 [法厄同](../分支时间线/法厄同/词条/参与者/势力/异魔.md)，指挥官写在 [击魄](../分支时间线/法厄同/击魄/02-暗线/03-参与者/污染/异魔指挥官.md)，地面称呼写在 [城市与城邦](../分支时间线/泰拉/地面/诸城所在之地/词条/参与者/势力/异魔（渊魔）.md)。

## 本层留什么

| 轴 | 只存 | 为什么留在本层 |
|----|------|----------------|
| [时间](时间/README.md) | 时代先后；法厄同按五段记 | 全库一套刻度 |
| [地点](地点/README.md) | 天体、地表、轨道、以太界、云城 | 空间是共用坐标，一处一个文件夹；同一地点不会因故事不同而有两种位置 |
| [事件](事件/README.md) | 跨区的「谁对谁做了什么」，单篇，归发起区 | 事件本身就是接口，拆开就会各说一套 |
| [参与者](参与者/README.md) | 被多个故事共用且事实相同的那部分 | 事实只有一份，没必要复制 |

其余参与者与概念随故事走。地点不随故事搬动：地点是共用的，故事只是引用它。
