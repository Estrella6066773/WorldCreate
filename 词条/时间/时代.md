# 时代

## 概述

各区年表不对齐到同一张总表。法厄同带按下面五段记先后。

## 法厄同

| 阶段 | 状态 |
|------|------|
| 大灾变前 | 三家地上主要势力在环带落下最初据点，组成云邦。云上人任航班司机、监测站管理员。船可以跨越真空，沿抛物线航行 |
| 灾后 | 以太航道失效，环带与外界失联。地方势力不再听从云邦。船贴着小行星带绕行，矿主圈占绕行经过的地段。麦哲伦号从法厄同旁高速经过，向环带送出消息 |
| 环带内战期间 | 核心区处理这份消息时过于忽视边缘区意见，随后以云邦会议的名义把协约体改组为战时政权。边缘区势力组成矿业联盟，双方在法厄同交战 |
| 亚冷战期间 | 烈度下降。云城邦联与矿业联盟仍处敌对，没有正式停战。锚点航行开始修复本带航道 |
| 抗击异魔期间 | 异魔自马尔斯轨道外溢进入本带，迫使双方宣布休战，各自组织反异魔武装，再组成反异魔阵线。击魄写这段 |

过程见 [大天灾](../事件/大天灾.md) 与 [环带前史](../../分支时间线/法厄同/环带前史.md)。
