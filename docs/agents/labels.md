# 工作标签

issue 标签分三组，与本地待办表的三列对应，全部用中文。完整口径见 `_规范/待办/README.md`。

## 影响面

| 标签 | 含义 |
| --- | --- |
| `核心` | 不补会卡住跨区接口、整段剧情或专名的首次出现 |
| `重要` | 本区写不完、写不顺，但不挡别的区 |
| `补充` | 专名、细目、锦上添花 |

## 急迫度

| 标签 | 含义 |
| --- | --- |
| `急` | 阻塞，随时可以打断当前工作 |
| `高` | 这一轮就要写 |
| `中` | 排进最近几轮 |
| `低` | 有余力再做 |

## 负责

| 标签 | 含义 |
| --- | --- |
| `作者` | 需要拍板：设定取舍、因果、专名 |
| `编辑` | 可以在既有框架内补写、统一说法 |
| `智能体` | 可交给 AI 代笔，草稿由作者验收 |
| `待核实` | 先确认事实与正史是否冲突 |

## 使用规则

- 每条 issue 三组各打**一个**，不多打、不漏打。
- 状态不设标签：开着是没办完，关掉是办完了。
- 标签与本地表一致；改标签后跑 `python _规范/工具/同步索引.py` 重建表。
- 本仓库不处理外部提交的 issue，因此不设 triage 状态标签。收到外部 issue 时先人工判断，再按上表打标签。
