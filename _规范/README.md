本目录收**仓库级约定**：怎么写、怎么改、待定放哪、条目长什么样。设定真相本身不在这里，在 [词条](../词条/README.md) 与 [分支时间线](../分支时间线/README.md)。

## 与模板的关系

[_templates/](../_templates/README.md) 放各类文档的骨架。骨架只是起点：写完后删掉没有内容的小节，不要为对齐模板而填充空话。

## 约定优先于习惯

本目录写下的规则，与某个文件里已有的写法冲突时，**以本目录为准**；改不动的地方先在待办里登记一条，不要悄悄沿用旧写法。
