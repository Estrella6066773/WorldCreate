# UI风格指南

> 色彩、明度与照明总则见 [视觉基调与色彩体系](../00-总纲/视觉基调与色彩体系.md)。
> 马利克说后续再定具体的，《深空梦里人》的极简风格 UI 没有什么特别值得参考的地方。

## 核心原则

界面是舰船与设施的操作层，不是独立的手机应用。它应像嵌入金属外壳的显示屏或投影：深色底、细线框、模块化容器和明确的功能状态。信息优先于装饰，任何视觉元素都必须帮助玩家读取状态、位置或下一步操作。

## 两类界面

| 类型 | 使用场景 | 视觉语言 |
|---|---|---|
| 系统面板 | 船体状态、模块、资源、设备控制 | 线框连线、槽位卡片、数值与横向状态条 |
| 任务提示 | 对话、目标、交互确认、返回操作 | 黄线分隔、白色主文本、黄色关键词、简洁箭头 |

两类界面共享字体、总纲颜色角色与边距基准，但任务提示不应硬塞进复杂的仪表容器。

## 布局与组件

- **面板：** 深青黑或深石墨底，使用 1 像素至 2 像素等效的冷灰细线分区；外框仅用于划定功能区域，不叠加双重装饰边框。
- **模块槽位：** 方形或近方形卡槽承载设备、部位或可替换模块；相邻槽位可用细线路径表达连接关系。
- **状态条：** 采用短段横条，长度和填充量表达数值，颜色表达状态；不得只依赖颜色传递关键含义。
- **图标：** 以简化线框、几何轮廓和清楚的剪影为主。同一界面中统一使用线框或实心高亮，不混用多种渲染风格。
- **文字：** 冷白用于主要内容，灰白用于次要参数，黄色仅突出行动词、目标名或当前选择。保证背景与正文有足够明度差。

## 状态颜色

| 状态 | 颜色 | 规则 |
|---|---|---|
| 正常 / 可用 | 冷白、低饱和青 | 用于稳定数值与已连接系统 |
| 已选中 / 当前目标 | 暖黄 | 同时以边框、下划线或图标状态标识 |
| 注意 / 资源不足 | 琥珀黄 | 使用短促提示，不持续闪烁 |
| 危险 / 损坏 / 不可用 | 红色 | 仅用于需要立刻处理的状态 |
| 锁定 / 次要 / 不可交互 | 深灰 | 必须降低对比度，不模拟可点击按钮 |

## 动效与反馈

- 点击或确认：100–180 毫秒的亮度切换、描边收束或状态条填充即可。
- 数值变化：优先改变数值和状态条，再给予一次短促高亮；避免整块面板位移。
- 告警：红色脉冲只作用于对应组件，并在状态解除后停止；禁止全屏持续闪烁。
- 页面切换：使用淡入、裁切或小幅滑入，保持 HUD 和局内视觉锚点稳定。
