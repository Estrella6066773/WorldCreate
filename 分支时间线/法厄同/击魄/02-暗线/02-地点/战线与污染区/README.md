# 战线与污染区

## 概述

反异魔阵线的防线是一条战线，[腐化](../../03-参与者/污染/腐化.md)蔓延之后又扩大出一片污染区。两者都落在[舞台](../舞台/README.md)之内。

## 范围

- 战线是阵线防线所在。腐化爆发之后，战线逐步溃退。
- 污染区随腐化蔓延而扩大。
- 佣兵团前往要塞时，必须穿过这条可能已经遭到腐化的战线。
