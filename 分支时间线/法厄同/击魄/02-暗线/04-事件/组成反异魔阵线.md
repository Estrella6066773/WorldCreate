# 组成反异魔阵线

## 概述

休战之后，[云邦](../03-参与者/云邦.md)与[矿业联盟](../03-参与者/矿业联盟.md)各自组织反异魔武装，再组成[反异魔阵线](../03-参与者/反异魔阵线.md)。

## 过程

1. 双方宣布休战，见 [外溢迫使休战](外溢迫使休战.md)。
2. 各自组织自己的反异魔武装。
3. 再组成反异魔阵线。
4. 许多佣兵作为自由佣兵接受雇佣，或代表独立云城、独立空间站加入。

本集从阵线已经组成写起。
