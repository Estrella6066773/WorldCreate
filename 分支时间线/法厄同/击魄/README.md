# 击魄

击魄（工程名 **CoreJack**）的子设定集。主场在[法厄同](../../../词条/地点/法厄同/README.md)带朝向[马尔斯](../../../词条/地点/马尔斯/README.md)的那一侧所见。时间落在破晓时代后段：亚冷战之后，[异魔](../../../词条/概念/异魔.md)外溢迫使[云城邦联](../../../词条/阵营/云邦.md)与[矿业联盟](../../../词条/阵营/矿业联盟.md)真正休战，双方组成反异魔阵线。

> **层级：** 母设定（本仓库根目录：总世界线 · 词条 · 分支时间线）→ **本集**  
> **不含：** 程序实现、玩法系统与编辑器文档。  
> 与母设定同世界、不同时期、不同舞台。本集只链母设定，不链其它子设定集。

---

## 一句话

马尔斯轨道的穿越机污染外溢进入法厄同带，本带称之为异魔。亚冷战只是烈度下降，不是休战。外溢之后，云城邦联与矿业联盟宣布休战，各自组织反异魔武装，再组成**反异魔阵线**。击魄写的就是这段阵线。舰上驾驶意识统称机魂。

## 架构

两层正交：

1. **知情分层（明线／暗线）**：玩家所见所信，对世界真相。
2. **存储轴（时间／地点／参与者／事件）**：每一条知情线内部都按这四条存放。

参与者＝能作主语的一方：个体、势力、国家，以及异魔、腐化、机魂等能发出动作的对象。

四条线内部可以再分，不必摊平，也不必明暗对称。地点按空间嵌套（一处一个文件夹）；参与者按佣兵团／势力／污染／机魂；事件按阶段；时间在暗线另立本集之前的时期。分层对齐 [分支时间线](../../README.md)，地点嵌套对齐 [词条/地点](../../../词条/地点/法厄同/README.md)。

| 线 | 只存 | 不存 |
|----|------|------|
| 时间 | 阶段先后、本集起点 | 谁做了什么的过程 |
| 地点 | 舞台、战线、污染区、要塞 | 在该处发生的事件全文 |
| 参与者 | 是谁、本集时点状态 | 事件因果链 |
| 事件 | 谁对谁做了什么 | 把履历或地理志写进事件 |

写作明线只引 `01-明线`；设计暗线／反转引 `02-暗线`；查矛盾用对照表。
