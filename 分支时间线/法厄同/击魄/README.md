# 击魄

击魄（工程名 **CoreJack**）是[法厄同](../../../词条/地点/法厄同/README.md)带的一部子设定集，写环带朝向[马尔斯](../../../词条/地点/马尔斯/README.md)那一侧发生的事情。时间落在抗击异魔期间：此前[云城邦联](../词条/参与者/势力/云邦.md)与[矿业联盟](../词条/参与者/势力/矿业联盟.md)只是僵持，[异魔](../../../词条/参与者/污染/异魔.md)外溢之后，双方才真正休战，组成反异魔阵线。

> **层级：** 母设定（[00-总览](../../../00-总览/README.md) · [总世界线](../../../总世界线.md) · 词条按时间／地点／参与者／事件 · 分支时间线）→ **本集**  
> **不含：** 程序实现、玩法系统与编辑器文档。  
> 与母设定同世界、不同时期、不同舞台。本集只链母设定，不链其它子设定集。

---

## 一句话

马尔斯轨道的穿越机污染外溢进入法厄同带，本带称之为异魔。僵持只是双方打不动了，不是休战。外溢之后，云城邦联与矿业联盟宣布休战，各自组织反异魔武装，再组成**反异魔阵线**。击魄写的就是这段阵线。

作者希望玩家在这一段里指挥的舰船，是法厄同环带内部或边缘的运输机、战斗机和无人机。行星之间的航行，作者拿海上的轮船和战舰作对照。这一句只记作者要的尺度，不另立一种船。

## 架构

两套切法，互不替代：

1. **知情分层（明线／暗线）**：玩家所见所信，对世界真相。
2. **存储轴（时间／地点／参与者／事件）**：每一条知情线内部都按这四条存放。

参与者指能作主语的一方：个体、势力、国家，以及异魔、腐化这类能发出动作的对象。

四条线内部可以再分，不必摊平，也不必明暗对称。地点按空间嵌套，一处一个文件夹；参与者按佣兵团、势力、污染划分；事件按阶段划分；时间在暗线另立本集之前的时期。分层对齐 [分支时间线](../../README.md)，地点嵌套对齐 [词条/地点](../../../词条/地点/法厄同/README.md)。

| 线 | 只存 | 不存 |
|----|------|------|
| 时间 | 阶段先后、本集起点 | 谁做了什么的过程 |
| 地点 | 舞台、战线、污染区、要塞 | 在该处发生的事件全文 |
| 参与者 | 是谁、本集时点状态 | 事件因果链 |
| 事件 | 谁对谁做了什么 | 把履历或地理志写进事件 |

写明线文案只引 `01-明线`；设计暗线与反转引 `02-暗线`；查两线矛盾看对照表。
