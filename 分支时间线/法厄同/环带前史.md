# 环带前史

> 地点：[法厄同](../../词条/地点/法厄同/README.md)（主场），基建见 [泰拉轨道服务器阵列](../../词条/地点/泰拉/轨道/泰拉轨道服务器阵列/README.md)。此后的事分三处承接：战后微观在 [云上坟场](云上坟场/README.md)，破晓反异魔阵线在 [击魄](击魄/README.md)，麦哲伦号舰内见 [循光之城](../麦哲伦号/循光之城.md)。近地与马尔斯在失联之后如何治理，后续再议。

[云邦](../../词条/参与者/势力/云邦.md)（云城邦联／Orbis／CCC）是法厄同带上由各州组成的联合国式协约体，不是太阳系政权，只存在于法厄同带。本篇记灾前的云城布点与云邦结成、麦哲伦号过境送来的第一份外界消息、环带大战，以及大战之后的重建；麦哲伦号与法厄同地区没有从属关系，本带只写本带所见。

## 云城布点

云上技术先落地——指意识上传。各势力各有自己的云城，泰拉轨道上建起服务器阵列。云城在太阳系各地布点，但**并不组成一个名叫云邦的全系政权**。

在法厄同带上，三家地上主要势力的最初落脚地成为三个创始州，即核心区，它们组成云邦。最大铀矿在东亚合作社那一创始州附近。云上人由三类人构成：求长生的翘楚、弃残躯的病患、贪权财的庸才。上传只继承学识、记忆与习惯，存续仍靠资源，因此云上人多任航班司机或监测站管理员。早期云城仅供云上人；此后有大型云城加入人居结构，但人身自由与权限不及云上人。

灾前，协议相连且距离足够近的云城节点可以直接传递云上人的实例。大灾变后，以太性质异变使远距离实时传输不再稳定，实例可能在传输中丢失或畸变，跨城往来因此重新依赖物质舰船，太空活动上云上人日渐与肉身人类差别不大。

### 各轨道上的云城（灾前产业）

| 所在 | 云城与轨道设施的主要角色 |
|------|--------------------------|
| 泰拉轨道、马尔斯轨道 | **没有**规模很大的工业云城。产业以服务业为主，仅有少量轻工业。轨道上的云城与空间站多为驿站、服务站与景点。泰拉轨道另有服务器阵列，作为当地云端底座。这些地方不叫云邦。 |
| 马尔斯 | 仍在开发中。多数云城负责勘探与科考，一部分做贸易，少量负责工业。自行管辖，不叫云邦。 |
| 卢娜（月面） | 灾前星系工业中心，向外输出高级机器。月球工业基地是东亚合作社（名称待定）的手笔。麦哲伦号在此建造。详见 [月人的起源](../卢娜/月面/月人的起源.md)。 |
| 法厄同带 | **云邦**所在。三个创始州即核心区，分别对应三家地上主要势力的最初落脚地。最大铀矿在东亚合作社那一创始州附近。边缘区为偏远、还在开发的地带。领地尚未成州。 |

## 云上世界的构造与共识（设定真相）

旧文明构想世界的底层由规则与信息构成：信息聚成的纯粹维度即**信息海**，规则对信息施加影响、使其形成能够响应和产出的结构。旧文明以电子设备模拟这个构想，在模拟出的场域中注入数据与规则；再演化出能够处理规律的高级智能，并以这些智能为脚手架搭建起模仿现实世界的数字维度。这个维度即**云上世界**（详见概念词条：[信息海](../../词条/概念/信息海.md)、[云上世界](../../词条/概念/云上世界.md)）。

云上人上传之后，其思维实例栖居在由空间站或服务器集群承载的**云城**节点中；各云城之间共享底层逻辑，使云上人在不同节点之间仍能被识别为同一人。灾前，协议相连且距离足够近的节点可以在电子设备之间直接传递云上人的实例。大灾变后，以太性质异变使这种通道不再稳定、不再安全，实例可能在传输中丢失或畸变，因此各云城不允许再用它运输云上人，转而使用物质世界的舰船运送人员与载体。但简单信息或虚拟世界物品仍可在风险自负的前提下继续通过残破通道传递。统一的云上世界随之崩溃为许多规则各异的小世界，但底层逻辑仍在，使不同云城之间仍可往来。

> 本小节只在设定真相层使用。圈内叙述通常只说云城是空间站与生活区，云上世界是这些站点的集合，不会涉及信息海与云上世界底层来源。

## 麦哲伦号：建造与预定航路

麦哲伦号在卢娜建造（月球工业基地是东亚合作社的手笔），争议大；完工后转入泰拉轨道，完成出航仪式、补给与编队，再离开。它是泰拉体系的远航工程，不是云邦的船。使命：前往麦哲伦云（不宜人居，但有不受大气保护的物质）做云上殖民。

**预定航路（表象层）：** 从泰拉轨道启航 → 前往木星 → 借木星**引力弹弓**获得初速度 → 加速到理想速度，使「麦哲伦号已经成功出航」成为既成事实 → **再**潜入以太界，继续加速，沿以太航流前往麦哲伦云。

以太接近命运、规律与世界本源。表象与本源相互影响，如同风与海。麦哲伦号必须在表象层真正出发，才能在以太界掀起可乘的航流（如同风推动水面形成洋流），再潜入以太界、沿航流行进；这样可以提高抵达目的地的把握、减少途中变故，并相对表层抄近路。木星引力弹弓是表象层的理想力学方案，不是掀起航流的那一阵风；那一阵风是弹弓之后加速到理想速度、使成功出航成为既成事实。

已删除、不再使用：织机引擎（不再写「投送舰体、抵达早于启航」）；登上麦哲伦号夺取舰体、以及地上国支持者为此发动的叛乱；「近地叛乱主导者／近地最大碎片势力」。

## 断航与过境

大天灾中，远程航道被以太乱流切断，远距通讯失效，各区受管辖程度大降。此时麦哲伦号已竣工启航，在**抵达法厄同带之前**遭遇大天灾。舰体尚未越过马尔斯，不进入港口停泊；在附近单方面观测到马尔斯受创，得知其他地区亦遭波及、损失惨重，但不知详情，对方不响应通讯。

舰体仍按预定航路前进，以指定速度准备进入木星引力弹弓，因此**不减速、不进入港口停泊**。从法厄同旁经过时：近距通讯仍可用；船体远超一般远行舰，航路附近的云邦州可派遣使者往来、建立联络。主要是核心区（尤其东亚合作社那一片创始州）派得上使者。这是法厄同与外界失联以来**第一份来自外界的消息**。麦哲伦号与法厄同地区没有从属关系；送出消息后继续前往木星，并尽量完成引力弹弓。潜入以太界做得到；对环带和近地，结果与风险留白。

## 环带大战

核心区处理这份受灾消息时过于忽视边缘区意见。随后，核心区希望把已经分散到各州和领地的权力收回，集中调度（征用船只、征用矿产、统一指挥），以云邦会议的名义把协约体改组为战时政权。边缘区势力（含大量矿主）不满，组成 [矿业联盟](../../词条/参与者/势力/矿业联盟.md) 并走向独立，在法厄同交战。东亚合作社那一创始州附近握有最大铀矿与反应堆链，但战后无力收复失地；联盟控制大片区域。环带废墟成为战后空间站给养来源。细节见 [云上坟场](云上坟场/README.md)。

## 重建与后续

改良航行：锚点 + 结界。云上人按底层协议不得直接跨空间传输，须乘特制航天器；同一轨道内短距定向传输允许且抗乱流。环带自此开始重建部分航道。

更晚：马尔斯轨道穿越机污染外溢进入本带；亚冷战之后，云城邦联与矿业联盟宣布休战、组成反异魔阵线，见 [击魄](击魄/README.md)。
