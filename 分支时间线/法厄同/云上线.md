# 云上线

> 地点：[法厄同](../../词条/地点/法厄同/README.md)（主场）· 基建见 [泰拉轨道服务器阵列](../../词条/地点/泰拉/轨道/泰拉轨道服务器阵列/README.md)。战后微观：[云上坟场](云上坟场/README.md)。破晓反异魔阵线：[击魄](击魄/README.md)。舰内子设定：[循光之城](../麦哲伦号/循光之城.md)。云邦只等于法厄同带上的联合国式协约体。近地与马尔斯在失联之后如何治理——后续再议。

[云邦](../../词条/阵营/云邦.md)（云城邦联／Orbis／CCC）是法厄同带上由各州组成的联合国式协约体，不是太阳系政权。麦哲伦号是泰拉体系的远航工程，不是云邦的船：在卢娜建造，从泰拉轨道启航，赴木星途中遭遇大天灾。舰体从法厄同旁高速经过时，向已经与外界失联的环带送出第一份来自外界的消息。核心区处理这份消息时过于忽视边缘区意见，随后又要把已经分散到各州和领地的权力收回、集中调度，以云邦会议的名义把协约体改组为战时政权。边缘区势力结成矿业联盟并独立，环带大战把法厄同打成废墟。破晓时以锚点重建部分航道。麦哲伦号与法厄同地区没有从属关系；本带只写本带所见。

## 各轨道上的云城（灾前产业）

**云邦只存在于法厄同带。** 其它轨道的云城各归宗主势力或自行管辖，各有独立合作体系。

| 所在 | 云城与轨道设施的主要角色 |
|------|--------------------------|
| 泰拉轨道、马尔斯轨道 | **没有**规模很大的工业云城。产业以服务业为主，仅有少量轻工业。轨道上的云城与空间站多为驿站、服务站与景点。泰拉轨道另有服务器阵列，作为当地云端底座。这些地方不叫云邦。 |
| 马尔斯 | 仍在开发中。多数云城负责勘探与科考，一部分做贸易，少量负责工业。自行管辖，不叫云邦。 |
| 卢娜（月面） | 灾前星系工业中心，向外输出高级机器。月球工业基地是东亚合作社（名称待定）的手笔。麦哲伦号在此建造。详见 [月面线](../卢娜/月面/月面线.md)。 |
| 法厄同带 | **云邦**所在。三个创始州即核心区，分别对应三家地上主要势力的最初落脚地。最大铀矿在东亚合作社那一创始州附近。边缘区为偏远、还在开发的地带。领地尚未成州。 |

## 时间线

### 前文明末期

云上技术先落地（意识上传）。各势力已有各自的云城。泰拉轨道建服务器阵列。云城在太阳系各地布点，但**并不组成一个名叫云邦的全系政权**。法厄同带上，三家地上主要势力的最初落脚地组成云邦（各州加盟的联合国式协约体）。云上人构成：求长生的翘楚、弃残躯的病患、贪权财的庸才。上传只继承学识、记忆与习惯；存续仍靠资源，多任航班司机或监测站管理员。因以太干扰不能远距传意识，太空活动上与人类差别不大。早期云城仅供云上人；后有大型云城加入人居结构，但人身自由与权限不及云上人。

**麦哲伦号**在卢娜建造（月球工业基地是东亚合作社的手笔），争议大；完工后转入泰拉轨道，完成出航仪式、补给与编队，再离开。它是泰拉体系的远航工程，不是云邦的船。使命：前往麦哲伦云（不宜人居，但有不受大气保护的物质）做云上殖民。

**预定航路（表象层）：** 从泰拉轨道启航 → 前往木星 → 借木星**引力弹弓**获得初速度 → 加速到理想速度，使「麦哲伦号已经成功出航」成为既成事实 → **再**潜入以太界，继续加速，沿以太航流前往麦哲伦云。

以太接近命运、规律与世界本源。表象与本源相互影响，如同风与海。麦哲伦号必须在表象层真正出发，才能在以太界掀起可乘的航流（如同风推动水面形成洋流），再潜入以太界、沿航流行进；这样可以提高抵达目的地的把握、减少途中变故，并相对表层抄近路。木星引力弹弓是表象层的理想力学方案，不是掀起航流的那一阵风；那一阵风是弹弓之后加速到理想速度、使成功出航成为既成事实。

已删除、不再使用：织机引擎（不再写「投送舰体、抵达早于启航」）；登上麦哲伦号夺取舰体、以及地上国支持者为此发动的叛乱；「近地叛乱主导者／近地最大碎片势力」。

### 大天灾

远程航道被以太乱流切断，远距通讯失效，各区受管辖程度大降。麦哲伦号已竣工启航，在**抵达法厄同带之前**遭遇大天灾。舰体尚未越过马尔斯，不进入港口停泊；在附近单方面观测到马尔斯受创，得知其他地区亦遭波及、损失惨重，但不知详情，对方不响应通讯。

舰体仍按预定航路前进，以指定速度准备进入木星引力弹弓，因此**不减速、不进入港口停泊**。从法厄同旁经过时：近距通讯仍可用；船体远超一般远行舰，航路附近的云邦州可派遣使者往来、建立联络。主要是核心区（尤其东亚合作社那一片创始州）派得上使者。这是法厄同与外界失联以来**第一份来自外界的消息**。麦哲伦号与法厄同地区没有从属关系；送出消息后继续前往木星，并尽量完成引力弹弓。潜入以太界做得到；对环带和近地，结果与风险留白。

**环带大战：** 核心区处理这份受灾消息时过于忽视边缘区意见。随后核心区希望把已经分散到各州和领地的权力收回，集中调度（征用船只、征用矿产、统一指挥），以云邦会议的名义把协约体改组为战时政权。边缘区势力（含大量矿主）不满，组成 [矿业联盟](../../词条/阵营/矿业联盟.md) 并走向独立，在法厄同交战。东亚合作社那一创始州附近握有最大铀矿与反应堆链，但战后无力收复失地；联盟控制大片区域。环带废墟成为战后空间站给养来源。细节见云上坟场。

近地与马尔斯在失联之后如何治理，后续再议。三家地上主要势力（欧亚国同盟、东亚合作社、大洋州联邦）的正式名称仍待定。

### 破晓时代

改良航行：锚点 + 结界。云上人按底层协议不得直接跨空间传输，须乘特制航天器；同一轨道内短距定向传输允许且抗乱流。开始重建部分航道。更晚：马尔斯轨道穿越机污染外溢进入本带；亚冷战之后，云城邦联与矿业联盟宣布休战、组成反异魔阵线，见 [击魄](击魄/README.md)。

## 待补
