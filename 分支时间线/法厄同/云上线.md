# 云上线

> 地点：[法厄同](../../词条/地点/法厄同/README.md)（主场）· 基建见 [泰拉轨道服务器阵列](../../词条/地点/泰拉/轨道/泰拉轨道服务器阵列/README.md)。战后微观：[云上坟场](云上坟场/README.md)。舰内子设定：[循光之城](../麦哲伦号/循光之城.md)。已敲定：麦哲伦号航路、环带核心区、飞掠传讯与环带大战爆点。近地碎片化、地上国后续、是否潜入以太界——后续再议。

云邦（云城邦联／Confederation of Cloud Cities；Orbis／CCC；旧称矩阵联合）由各势力云城加盟、地上国协约共建。灾前扩张云城、开建麦哲伦号；竣工后从泰拉轨道启航，赴木星途中遭遇大天灾。麦哲伦号飞掠法厄同时送来孤岛以来第一份外界消息；**环带核心区**势力随即试图把协约收成战时政权，边陲矿主反对，环带大战把法厄同打成废墟。破晓时以锚点重建部分航道。麦哲伦号与法厄同没有从属关系；本带只写本带所见。

## 各轨道上的云城（灾前产业）

太阳系云邦**没有**一个叫「核心区」的全系中枢。「核心区」专指法厄同带内的铀矿工业区。

| 所在 | 云城与轨道设施的主要角色 |
|------|--------------------------|
| 泰拉轨道、马尔斯轨道 | **没有**规模很大的工业云城。产业以服务业为主，仅有少量轻工业。泰拉地面与月面工业更成熟；月面更适合发展工业。轨道上的云城与空间站多为驿站、服务站与景点。泰拉轨道另有服务器阵列，作为云端底座。 |
| 马尔斯 | 仍在开发中。多数云城负责勘探与科考，一部分做贸易，少量负责工业。 |
| 卢娜（月面） | 灾前星系工业中心，向外输出高级机器。麦哲伦号在此建造。星系尺度上，来自卢娜等同于来自泰拉体系。详见 [月面线](../卢娜/月面/月面线.md)。 |
| 法厄同带 | 云邦前沿。**环带核心区**建在本带最大铀矿矿区，是带内工业相对发达的区域。边陲以采矿与中低附加值产品为主。 |

## 时间线

### 前文明末期

云上技术先落地（意识上传）。各势力已有各自的云城，再签云城邦联协约，以云上亚区块链协同治理。泰拉轨道建服务器阵列。云城网络在太阳系扩张、搭空间站。云上人构成：求长生的翘楚、弃残躯的病患、贪权财的庸才。上传只继承学识、记忆与习惯；存续仍靠资源，多任航班司机或监测站管理员。因以太干扰不能远距传意识，太空活动上与人类差别不大。早期云城仅供云上人；后有大型云城加入人居结构，但人身自由与权限不及云上人。

**麦哲伦号**在卢娜建造，争议大；完工后转入泰拉轨道，完成政治出航、补给与编队，再离开。使命：前往麦哲伦云（不宜人居，但有不受大气保护的物质）做云上殖民。

**预定航路（表象层）：** 泰拉轨道启航 → 赴木星 → 借木星**引力弹弓**获得初速度 → 加速到理想速度，坐实「成功出航」这一既定事实 → **再**潜入以太界，持续加速，乘以太航流前往麦哲伦云。

以太接近命运、规律与世界本源。表象与本源相互影响，如风与海。麦哲伦号必须在表象层真正出发，才能在以太界掀起可乘的航流（如风推水面成洋流），再潜入乘流；潜入可提高抵达确度、减少变故，并相对表层抄近路。木星引力弹弓是表象层的理想力学方案，不是「风」本身；风是弹弓之后达到理想速度所坐实的成功出航。

已删除：织机引擎（不再使用「投送舰体、抵达早于启航」）；登舰与夺舰叛乱；「近地叛乱主导者／近地最大碎片势力」。

### 大天灾

远程航道被以太乱流切断，远距通讯失效，各区受管辖程度大降。麦哲伦号已竣工启航，在**抵达法厄同带之前**遭遇大天灾。舰体尚未越过马尔斯，不停泊；在附近单方面观测到马尔斯受创，得知其他地区亦遭波及、损失惨重，但不知详情，对方不响应通讯。

舰体仍按预定航路前进，以指定速度准备进入木星弹弓，因此**不减速、不停泊**。途经法厄同时飞掠：近距通讯仍可用；船体远超一般远行舰，环带云邦可派遣使者往来、建立联络。这是法厄同失联以来**第一份来自外界的消息**。麦哲伦号与法厄同没有从属关系，传讯后继续赴木星，并尽量完成引力弹弓。能否潜入以太界，后续再议。

**环带大战：** 悲报落地之后，**环带核心区**的云城势力组成政治团体，试图把松散邦联收成战时政权（征船、征矿、统一指挥，要求整条环带服从）。边陲矿主反对，武装抵抗，组成 [矿业联盟](../../词条/阵营/矿业联盟.md)，战于法厄同。环带核心区握最大铀矿与反应堆链，但无力收复；联盟控制大片区域。环带废墟成为战后空间站给养来源。细节见云上坟场。

近地与马尔斯在失联之后如何碎片化、地上国如何行动，后续再议。

### 破晓时代

改良航行：锚点 + 结界。云上人按底层协议不得直接跨空间传输，须乘特制航天器；同一轨道内短距定向传输允许且抗乱流。开始重建部分航道。后续待补。

## 待补

近地与马尔斯在灾后的治理形态；地上国与轨道设施；麦哲伦号弹弓之后能否潜入以太界；破晓时代后段。
