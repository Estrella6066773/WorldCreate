# 分支时间线

按**地点分层**的故事目录。上层只索引；各线只写本区因果。跨区只留接口，不抄对方正文。地名与 [词条/地点](../词条/地点/泰拉/README.md) 对齐。总览与跨区接口见 [总世界线](../总世界线.md)。

行星定名为**泰拉**（旧称地球）。卫星定名为**卢娜**（旧称月球）；故事在**月面**，称月面线。不另建地点词条。不另立灵界、城与邦林立之地。

```
太阳系
├── 泰拉
│   ├── 轨道 → 以太线（研究站）／云上线（服务器阵列，正文在法厄同）
│   └── 地面 → 地面线（众城所在地）／精灵线（世界树）
├── 卢娜
│   └── 月面 → 月面线
├── 马尔斯 → 火星线
├── 法厄同 → 云上线
│   └── 云上坟场（战后微观）
└── 麦哲伦号（舰，属云上线）→ 循光之城
```
