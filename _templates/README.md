# 模板

| 字段 | 内容 |
|------|------|
| 状态 | 现行 |
| 最后更新 | 2026-11-08 |
| 适用范围 | 新建文档时取骨架 |

| 模板 | 用于 |
|------|------|
| [词条-参与者](词条-参与者.md) | 族群、势力、人物、污染、至高存在、机魂 |
| [词条-事件](词条-事件.md) | 跨区的「谁对谁做了什么」 |
| [词条-时间](词条-时间.md) | 时代、时期、年表 |
| [词条-概念](词条-概念.md) | 世界构造、智能形态、因果机制等抽象概念 |
| [地点README](地点README.md) | 一处一文件夹的 `README.md` |
| [分支时间线](分支时间线.md) | 各区故事正文与子设定集总览 |

## 用法

1. 复制最接近的骨架，改名成目标文件名。
2. **删掉用不上的小节**，不要为了对齐模板填空话。
3. 页脚按 [词条写作规范](../_规范/词条写作规范.md) 写；新文档也可改用表头元数据。
4. 正文不留待定清单，缺口登记到对应 `待办/` 文件。
