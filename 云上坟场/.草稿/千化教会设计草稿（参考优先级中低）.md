# 千化教会设计草稿（参考优先级中低）

> **对齐说明**：千化教会存在**两种口径**，指向同一件事——master 决议四十的「堆人格 / 造神」，与旧版草稿的「位相 / 归一」，是同一事实的两种说法（不互相取代）。本稿合并记录两种口径，正式决议以 master 分支的 [明线·千化教会](../01-明线/站内社会/千化教会.md) 与 [暗线·千化教会真相](../02-暗线/02-势力/千化教会（暗线真相）.md) 为准。

---

## 一、基本定义

- **名称：** 千化教会（官方定名已确认）
- **名称含义：** 「千化」指同一本体呈现出的无数形态。
- **经典：**《位相圣典》
- **教义核心（旧口径）：** 世人并非彼此孤立的本体，而是同一终极个体的不同位相；最终「众位相归一」。
- **性质（明线）：** 基金会性质组织，以基金会（Foundation）形态运作，业务横跨**金融、技术、宗教**三个领域。
- **真实事业（暗线）：** 「堆人格」——以人格的堆叠与融合为手段，最终创造教会自认为的「神」。
- **教义核心（新口径，你明确提出的命题）：** 「神以自己的样貌创造了人类」——世人面貌各异，每一份人格都是神之样貌的一块碎片；将这些碎片重新堆叠、归一，便能寻得神。工程口径即造神纲领：「人格的堆叠终将凝聚为神」，但「神」的具体形态不做教条定义。

## 二、明暗双线定位

| 层面 | 内容 |
|------|------|
| 明线（驾驶员所见） | 基金会网点（核心是一家**银行**）+ 宗教场所；横跨金融、技术、宗教三领域的势力 |
| 暗线（世界真相） | **独立外部势力**，深入 A 站，在战争两方（矩阵联合 / 矿业联盟）纵横交错；真实事业为「堆人格造神」 |

> 写作规范：明线内容可直接用于玩家可见文案；暗线内容**不得**泄底（见 [明暗对照表](../00-总览/明暗对照表.md)）。

## 三、寻神逻辑（教义核心）

> 本节为**宗教口径**——是教会的宣讲，不是写死的世界观设定。「神是否存在」世界观不表态。

「神以自己的样貌创造了人类」。世人面貌各异——每一份人格、每一张「脸」，都是神之样貌散落世间的一块碎片。

由此推出（教会的宣讲）：

1. 神以己样貌造人 → 人是神样貌的碎片；
2. 碎片散落为众位相 → 每一份人格都是神的一块碎片；
3. 将碎片重新堆叠、归一 → 逆向拼回神的全貌 → 寻得神。

在教会的宣讲中，这一命题还被用来解释三件事（宗教口径，不写死为设定）：

- **「位相」即「人格」**：因为「位相」就是神样貌的一块碎片；
- **「归一」即「堆人格」即「造神」**：因为归一就是拼回碎片；
- **「收集材料」即「采集神的碎片」**：战争档案、云上人残片、废墟服务器，都被宣讲为神的碎片。

## 四、《位相圣典》

- 教义核心（旧口径）：世人并非彼此孤立的本体，而是同一终极个体的不同位相。
- 经典载体：《位相圣典》——古老理赔准则、合同条款、判例与批注逐渐被编纂成《位相圣典》。
- **「位相人格」的扩张**：「位相人格」最初用于判定同一人的多个备份或副本是否属于同一个法律主体；该理论后来被扩张——如果一个人的多个副本只是不同位相，那么不同人也可能是更高层个体的不同位相。

## 五、环带众人的身份真相

> 以 master 的身份界定为准。

- **人类与人工智能并存**：环带众人并非全是人工智能，而是分「人类」与「人工智能」两大类，人工智能内部再分层。
- **人类（云上人）**：思维上传的人类，法律与道德身份认定为人类。学社（技术官僚）即属此类——他们是合法云上人，不是人工智能。
- **人工智能**：不是人类，包括被制造的智能存在与思维上传不合规者。
  - **非法人工智能（逃难者 / 自由政府）**：不合规上传，知道自己不是人，却坚信「我们是人」。
  - **人格化人工智能（驾驶员）**：被制造并注入「曾是人类的克隆人」记忆，不知道自己不是人。
- 站外尚有部分人类（如矿业联盟的部分矿主）。
- 千化教会公开承认正常人类与克隆人具有完全相同的人格地位。

## 六、历史起源

### 1. 金融互助时期

- 大灾变后的一段时期，环带仍主要受巨企控制。
- 意识事故、载具失事与重构需求激增，原有保险体系难以负担赔偿。
- 巨企雇员建立金融互助与意识救援机构，为无力承担重构费用者提供资金、担保与备份保管。
- 巨企最初支持该机构，是为了把救援和赔偿成本从企业转移给互助组织。

### 2. 宗教化

- 推动宗教化的人物来自巨企保险与理赔体系，曾任高级精算师、理赔主管或救济基金管理者。
- 他将一次性互助改造成持续性的共同信用制度。
- 他将意识备份、身份认证、债务继承和救援合同纳入统一管理。
- 互助机构最终演变为千化教会。

### 3. 创始人的隐性历史

- 创始人最初把位相理论当作降低重复赔付、维持债务继承的法律工具。
- 后来创始人自身发生意识分叉，两个副本同时主张原有身份、职位和财产。
- 这次事件使其成为真正的位相理论信徒。
- 此段属于创作侧掌握的隐性世界观，不作为主线揭露，也不向玩家完整展示。

### 4. 教会公开历史

- 教会承认自身起源于灾后金融互助与意识救援。
- 官方叙事宣称，创始人从「众人共同支付一个人的存续成本」中获得启示。
- 官方历史隐去巨企卸责、理赔控制和创始人的意识分叉纠纷。
- 互助基金被称为第一座教会，获救者名录被称为最早的位相名录。

### 5. 独立外部势力（master 决议四十）

- 千化教会不是 A 站内部产生的组织，而是站外的**独立势力**，势力深入 A 站，并在战争两方（矩阵联合 / 矿业联盟）内部纵横交错。
- **战争两方角色**：在两方内部**双向布教 + 收集材料**——布教是身份掩护，收集材料（战争档案、战死云上人的残片、废墟服务器等）是真实目的。教会在两方的体量有限，不是环带巨擘。
- **经济基础**：多重来源，主要靠**教众募捐 + 金融运作「钱生钱」**。教会在站外已有庞大信众基础与成熟的资本网络；站外教众构成复杂，不细化。

## 七、A 站分支与呈现

### 明线呈现（驾驶员所见）

- 以**基金会网点（银行）**与**宗教场所**两种形态并存：银行办理信贷、储蓄、担保、债务收购等金融业务；宗教场所开放布道与仪式。驾驶员看到的形象取决于接触的场合与视角。
- **银行的表面归属**：教会掌管的这家银行，名义上是**自由政府托管的官方金融机构**（站上官方口径如此），柜面由**「服务员」**打理——站上普通工作人员，驾驶员照常与它们打交道，只当它是站上正常的金融机构。

### 暗线内情（驾驶员不可知）

- **银行的三层结构**：银行名义上是自由政府托管的官方金融机构，**实际上由千化教会主导建立**——自由政府以「托管」名义提供合法外衣，教会实际掌握资金与控制权。柜面的服务员只是名义管理者，真实决策在教会手中。
- **自由政府知情且互利**：掌权的逃难者（非法人工智能）**知道教会的真实身份**，双方各取所需——教会获得**隐蔽试验场**，自由政府获得**外部金融 / 资源渠道**。
- **学社三派态度**：学社内部态度不一——部分被渗透拉拢（**亲教会派**）、部分警惕抵制（**保守派**）、部分默许互利（**技术合作派**）。
- **A 站试验场**：教会需要 A 站提供**技术母本 + 观测场**——逃难者「给人工智能注入记忆 / 技巧 / 人格」的技术是教会堆人格事业的母本；A 站虚拟社会是天然的群体人格观测场，教会暗中观察驾驶员的日常来积累人格数据。
- **知情的圈层结构**：知晓空间站真相的不是整个教会，而是教会内部的**成员圈**。教会分「成员」与「信众」两层——成员以**转化类 AI（逃难者）+ 云上人**为主，知晓空间站的真相；信众以**非转化类 AI**（被制造的人格化人工智能，即虚拟社会普通居民 / 驾驶员 / 服务员）为主，不知晓真相。少数「靠得住」的信众可被接纳为成员，并因此知晓真相——知情正是成员资格的门槛。

## 八、与学社的职能边界

| 机构 | 职能 |
|------|------|
| 学社 | 技术与科研；复活设施、服务器和意识重构的技术运维；判断意识能否修复及采用何种重构方案 |
| 千化教会 | 资金、信用、保险、身份担保、备份保管、救援合同和债务登记；决定由谁支付重构费用，以及重构者继承何种身份与债务 |

教会不负责维修、科研或服务器工程。

## 九、堆人格事业（暗线）

### 派系的真实样貌：模糊、悬而未决

「派系」不是教会的正式建制，而是教会内部真实存在、却边界模糊的诸多团体与倾向的总称，其真实图景无法穷举、无法定名。教会的真实组织正是由这些模糊团体构成的（见「组织结构」）。

这些团体的形态可能包括（**举例，非穷举**，也不点名任何具体团体）：

- 师承关系；
- 围绕某个技术方案的小组；
- 围绕某种「神观」的信徒小圈子；
- 跨辖区的旧关系网。

### 三大派系：对现有团体的粗浅归类

> master 决议四十列举了英杰派、凝聚派、众者派三派，并明确「三派只是主干，底下还有更多旁支和子脉」。

所谓「三大派系」，**只是设定者对目前已有的各路团体做的粗浅归类**，不是「教会内部只有三派」的硬设定：

- **事后性**：归类是不稳定的——任何一支新团体都可能打破这个归类；
- **可重叠**：一支团体的立场可能横跨两派，一个人也可能同时被两个标签覆盖；
- **不排他**：标签之外还有大量未被归类的团体与子脉，它们的存在方式同样是模糊、未定名、悬而未决的。

「三派」这一粗浅归类，覆盖了材料道德梯度的两端与中段——**历史数据（无害）→ 抽象群体特质（灰色）→ 真实云上人的人命（极端）**：

| 归类标签 | 被归入的倾向（master 决议四十） | 道德梯度 |
|------|------------------|----------|
| **英杰派** | 把历史上的英杰模拟出来融合；材料开放——战争双方人物档案 / 云上人记忆遗产 / 灾变前史 | 无害（历史数据） |
| **凝聚派** | 将一个群体的特质凝聚到一个个体身上（「群体」为抽象群体：职业 / 阶层 / 民族等），不限定现实人群 | 灰色（抽象群体） |
| **众者派** | 神是万千人类面相之总和；直接用云上人的人命堆叠融合（「数字奇美拉」仅为辅助理解的比喻，非神观定名） | 极端（活人命） |

### 技术硬规则

- 教会**自有独立技术体系**，用自己的服务器与协议堆人格——不依赖 A 站虚拟社会系统，A 站只是观测场与母本来源。这使其独立于自由政府系统运行。

### 「神」的定位（暗线）

- **教义核心**：造神纲领，神定义开放——「人格的堆叠终将凝聚为神」，但神的具体形态不做教条定义，留待工程验证。这正是各团体争夺教义话语权的根源（教义细节待定）。
- **「神」的定位**：「神」是**开放终点**，不做明确定义，不同派系对它的期待各有不同。
- **「神」与世界观的接口**：「神」是某种**以太层面的存在**，与世界深处的规则体系挂钩（⚠️ 此条只写暗线，与以太、大灾变的具体关系待定）。
- **「众位相终将归一」的公开教义**：普通信徒多将其理解为寓言、共同责任、死后理想或遥远未来；只有教会高层知道归一已经具备技术可行性，并掌握工程进度。
- **归一不要求每个个体同意**：教会认为个体无权阻止整体恢复完整。

## 十、债务与主角

- 千化教会曾在主角遭遇剧情杀事故时例行履行救援制度。
- 主角不是预言中的特殊人物，也不是教会预先选中的融合核心。
- 事故前，主角认为自己是一名正常人类飞行员。
- 教会「救下」主角后，主角的认知身份由正常人类转变为克隆人。
- 主角认知中的解释是：原有身体在事故中毁灭，只能通过意识复制获得替代身体。
- 底层真相是：主角原本就是人工智能，事故后经历备份重构与身份记录重分类。
- 事故的具体经过沿用主角故事，不在千化教会词条中另行扩写。

## 十一、债务制度

- 千化教会的贷款没有利息。
- 死亡、换船、意识重构与紧急救援会产生固定债务。
- 玩家可以通过打捞收入偿清债务。
- 每次成功返航后，教会强制从收入中划走一部分用于还债。
- 中期与后期的阵营任务可以大幅减少或注销债务。
- 债务清零后，玩家获得正式选择并加入阵营的资格。
- 债务清零前，玩家可以接受所有阵营的入门任务。
- 千化教会本身是可正式加入的阵营。
- 加入千化教会后，其他阵营的深层任务线关闭；普通交易、维修和基础委托仍可使用。

## 十二、债务人与信徒

- 接受教会救援或贷款不要求皈依。
- 债务人和信徒是两种不同身份。
- 偿债属于合同义务，不属于宗教奉献。
- 非信徒可以获得同样的无息贷款、身份见证和基础救援。
- 正式加入教会发生在债务清零之后，使加入行为不受现存债务强迫。

## 十三、公开形象

- 教会真诚提供救援，并非单纯骗局。
- 教会不因贫穷或克隆人身份羞辱债务人。
- 所有费用、扣款与合同条款公开列明。
- 教会不收取利息，但必定执行已签订的合同。
- 教会不会没收维持下一次出航所需的全部资金。
- 教会将催收解释为「归还共同体替该位相承担的存续成本」。
- 教会给予克隆人与正常人类同等的账户、合同、继承和人格资格。

## 十四、备份制度

- 接受教会救援者必须交存标准意识备份。
- 学社维护储存设备，教会拥有备份保管权。
- 备份用于身份连续性证明和未来救援。
- 债务清零只解除经济债权，不自动删除备份。
- 教会永久保存所有获救者的意识备份。
- 教会不会通过删除、损坏或篡改备份威胁债务人。
- 永久备份档案也是终极归一工程的意识基础。

## 十五、组织结构

> master 将「组织结构与代表人物」列为待定项。本稿采用「**派系 + 表面银行**」的组织框架；旧版草稿的「见证人 / 保管人 / 合议体」三者归类为**待定**（见文末），待继续完善。

### 表面银行（明线组织，驾驶员所见）

- 教会在 A 站以**基金会网点（银行）+ 宗教场所**示人。
- 银行名义上是**自由政府托管的官方金融机构**，柜面由**「服务员」**（非转化类 AI 捏造居民）打理。
- 对驾驶员而言，教会最常出现的面目就是「站上有钱的机构」——办理信贷、储蓄、担保、债务收购。

### 派系（暗线组织，真实形态）

- 教会的真实组织不是科层神职，而是**派系**——诸多边界模糊、无法穷举、无法定名的团体与倾向（见「堆人格事业」）。
- 三大派系（英杰派 / 凝聚派 / 众者派）只是对现有团体的**粗浅归类**，不是正式建制。
- 教会分「成员」与「信众」两层：成员（转化类 AI + 云上人）知晓空间站真相，信众（非转化类 AI）不知晓；少数靠得住的信众可被接纳为成员。
- 个别成员可以存在私人疑虑，但不会形成独立声望、任务线或阵营路线。

### 待定：神职科层（见证人 / 保管人 / 合议体）

> 以下为旧版草稿的三阶神职设计，现归类为**待定**——是否沿用、如何与「派系 + 表面银行」框架衔接，待继续完善。

**见证人**：同时承担神职、账户管理、合同签署与身份核验，负责贷款、还款、赦免和重构后的身份连续性见证。

**保管人**：管理意识档案、教会资产和合同解释，负责与学社协调备份设施的技术维护。

**合议体**：

- 千化教会没有单一最高教宗；
- 教会由小规模合议体领导；
- 合议体成员会进行有限记忆交换与短时意识连接；
- 合议体掌握归一工程的真实进度；
- 合议体成员尚未永久融合，会议结束后仍保持不同个体身份。

## 十六、A 站内的自治地位

- 千化教会在 A 站享有高度自治。
- 自由政府不能直接修改教会账目。
- 自由政府不能擅自调取意识备份。
- 自由政府不能撤换教会内部人员。
- 教会遵守 A 站的一般治安规则与财务披露要求。
- 教会不公开具体债务人的意识档案。
- 教会不是独立国家，但构成受到合同、信用和现实依赖保护的制度飞地。

## 十七、与巨企的关系

- 千化教会的信用、保险和身份担保跨越多个巨企辖区。
- 巨企本身也是教会救援、备份和清算服务的使用者。
- 巨企作为游戏主场敌人，不会主动攻击受到教会登记保护的目标。
- 受保护目标包括教会设施、正式人员、救援船、备份运输载具和特定避难区域。
- 普通信徒、债务人、临时承包者和私人飞船不继承教会豁免。
- 主角不会仅因负债或加入教会而免受巨企攻击。
- 巨企仍可通过审计、冻结资产、合同争议和代理人向教会施压。

## 十八、建筑与视觉

- A 站教会由旧保险理赔中心、信用清算所和意识备份库改造而成。
- 原有办事柜台成为合同与债务办理处。
- 排队大厅兼作集会与布道空间。
- 档案库被称为位相名录。
- 备份阵列是教会最神圣的区域。
- 旧企业编号、叫号系统和合同窗口仍被保留。
- 宗教图像以账户汇聚线、身份树和意识分支图为主。
- 神圣感来自秩序、重复、档案规模和持续运转的设备，而不是传统尖塔与超自然光芒。

## 十九、归一工程

- 「众位相终将归一」是公开教义。
- 普通信徒多将其理解为寓言、共同责任、死后理想或遥远未来。
- 只有教会高层知道归一已经具备技术可行性，并掌握工程进度。
- 归一完全是一项技术工程，不依赖已证实的超自然力量。
- 工程建立在意识可以读取、复制、迁移和重组的基础上。
- 教会长期经营的贷款、身份索引、永久备份与跨辖区信用网络，构成归一工程的基础设施。
- 归一不要求每个个体同意。
- 教会认为个体无权阻止整体恢复完整。

## 二十、暂缓内容

现阶段不继续设计：

- 肉身人类如何被纳入归一工程；
- 归一完成后，原有个体的记忆与人格是否仍然保留；
- 归一后的社会如何运行；
- 游戏结局之后的世界状态；
- 主角剧情杀事故的具体过程；
- 「神」的具体定义，及其与以太、大灾变的关系；
- 教义细节（造神纲领的具体内容、仪式、布道话术）；
- A 站教会的主流派系构成（英杰派 / 凝聚派 / 众者派这一「粗浅归类」之下，各路团体谁是站内主流、又有哪些未被归类的子脉）；
- 各团体的代表人物与组织结构；
- 驾驶员后期与教会的对抗 / 卷入形态；
- 教会与认知滤网 / 虚拟社会 / 反叛者的可能接口。

## 二十一、玩法建议（待主策评估）

以下内容不是世界观决议：

- 玩家加入千化教会后，可通过持续缴纳共同基金，换取标准复活、基础救援和基础飞船不再产生个人债务。
- 该制度可以把教会的「共同承担风险」教义转化为阵营专属经济规则。
- 是否采用、缴纳比例及数值平衡由主策决定。
