# 术语英文定名（已确认）

> **状态：** 已确认（2026-08-14）  
> 与 [云邦定名方案](云邦定名提案.md)、[基金会定名方案](基金会定名提案.md) 配套。

---

## 定名表

| 中文 | 英文 | 说明 |
|------|------|------|
| **云城** | **Cloud City**（复数为 Cloud Cities） | 联邦治理单元；云城联邦英文全称 **Federation of Cloud Cities** 中的 Cloud Cities 即此 |
| **云上人** | **Cloudtype** | 合规思维上传、法律上认定为人类的存在 |
| **离散AI**／离散人工智能 | **Dispersed AI** | 非人格化智能武器；常用称呼离散AI，全称离散人工智能 |

## 相关已定英文（对照）

| 中文 | 英文 |
|------|------|
| 云邦（简称） | Orbis |
| 云城联邦（全称） | Federation of Cloud Cities（FCC） |
| 学社 | The Collegium |
| 共信会 | The Fiducia |

## 用法

1. 中文正文仍以中文为主；双语、索引、对外设定表使用上表英文。  
2. 「云城联邦」不要拆成与「云城」无关的另造英文；Cloud City 与 FCC 必须同根。  
3. Cloudtype、Dispersed AI 为首字母规范写法（专名）。
