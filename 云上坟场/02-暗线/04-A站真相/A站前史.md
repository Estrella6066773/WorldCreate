# A 站前史：从采冰站到中转空间站

> ⚠️ 暗线（真相）内容，**不得**直接用于玩家可见文案。表层认知见 [明线 · 空间站A](../../01-明线/空间站/空间站A.md) 的「A 站的由来」节。

## 概述

战前环带小采冰公司，从一颗冰质小行星起家，扩张为「三座采冰站 + 一座中转空间站」——即 A 站前身，边陲小城。采冰公司为**环带本地产业**，大灾变切断跨轨道航道，采冰**环带内部短途航线**未受直接冲击。

覆盖公司起家到中转站建成、再到战争摧毁的完整时间跨度（2026-08-11·决议六十一）。

## 五个阶段

1. **起家**：中等冰质小行星，约 **1500–2000 人**，采集设施、切割、装船。
2. **扩张**：涨至 **约 2500 人**，物色更大含水小行星，引入**巨企N 技术**勘探采集——A 站与巨企N 最早实质联系（技术依附）。
3. **招工与再扩张**：第二颗小行星开发时首站人满；附近原生人工人被巨企自动化淘汰（云上人接手岗位），流入采冰公司；派近半人赴第二颗，准备第三颗——**自动化淘汰工人成为扩张劳动力**（决议六十四）。
4. **战争来临**：环带内战打响；矿工饭后谈资，长期**未影响**采冰站运作——战场在环带另一头。
5. **转型中转站**：第三颗采冰步入正轨时，**首颗采冰站将开采殆尽**；将首站结构从小行星脱离，工人迁至第四颗，原站点改造为**中转空间站**，迁至三颗小行星中心——**2000–3000 人**，边陲小城，即后来的 A 站。

## 关键时序

```
采冰站（1500–2000人）
  → 扩张（巨企N技术 + 云上人驻站）
  → 再扩张（自动化淘汰工人）
  → 环带内战（长期未波及）
  → 中转空间站（2000–3000人）
  →【环带大战波及】→ 受袭、被动脱离巨企N
  → 数月封锁 → 思维上传 → 虚拟社会
```

虚线之后见 [思维上传与逃难](思维上传与逃难.md)、[环带大战](../01-战争/环带大战.md)。

## 采冰业的终结

**死于战争，非市场**——云邦坚壁清野波及采冰设施与矿区，A 站失去采冰来源，采冰公司解体，幸存者转向打捞残骸。小行星工人（约 3000–4000 人）在坚壁清野中的结局（幸存上传 / 覆灭）未定，影响真实幸存者构成。
