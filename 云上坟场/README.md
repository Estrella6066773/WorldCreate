# 云上坟场

云上人（**Cloudtype**）专属**子设定集**。正文由 SpaceShip 当前版本的世界观设定完整移植而来，落在母设定 WorldCreate 之内，主场是法厄同环（环带）战后废墟。

> **层级：** 母设定（本仓库根目录：总世界线 · 词条 · 分支时间线）→ **本集**（环带微观、明暗双轨）  
> **不含：** SpaceShip 的程序实现、玩法系统与编辑器文档——那些仍属于游戏工程。  
> **来源快照：** SpaceShip `master` / `Est`（`b16fade`，2026-08-18）的 `01-设定设计/`。

---

## 一句话

大灾变切断航道之后，法厄同环变成一座漂浮的坟场：云城节点失联、云上人数据残骸与战争兵器四散。本集写的是这座坟场里的一座无人站点——A 站——以及驾驶员、学社、共信会与云邦残部如何在废墟中互相定义「谁还算人」。
